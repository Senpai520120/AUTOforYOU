## Правила для каждой сессии
1. Перед началом: `aws ec2 describe-instances --instance-ids i-017e7dfd9fced32f5` → при `stopped` — `start-instances`
   (IP тот же). SSH не пускает — сменился IP владельца: обновить правило 22 в SG на `<новый IP>/32`.
2. Флаги на всё время: `C2C_ENABLED=false`, `C2C_PUBLIC_POSTING_ENABLED=false`, `PAYMENTS_ENABLED=false`.
   Реальных пользовательских данных на стенде нет. IP сервера нигде не публиковать.
3. Секреты генерировать на сервере, в чат и git не выводить.
4. В конце сессии: итог в `PROGRESS.md` (что закрыто, что осталось) и напоминание владельцу остановить сервер
   (`aws ec2 stop-instances --instance-ids i-017e7dfd9fced32f5`). Останавливать сам — только по слову владельца.
5. Одна сессия — один блок ниже. Длинный вывод (тесты, логи) — через test-runner.
