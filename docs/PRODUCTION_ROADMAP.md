| Что проверяем | Как именно |
|---|---|
| **Регистрация с согласием** | Новый пользователь регистрируется → входит → видит свой профиль. Без галочки «Погоджуюсь» — регистрация заблокирована. |
| **Калькулятор стоимости** | Запрос по реальному кейсу (Copart broker, бензин 2.0L 2018, $5 000) → в ответе все статьи (аукционный сбор, фрахт, акциз, НДС, пенсионный) → итог совпадает с суммой. Флаг `is_estimate=true` всегда установлен. |
| **Оплата LiqPay** | Создание платежа → валидный callback → листинг разблокирован. Неверная подпись → отклонено, листинг не трогается. Повторный callback → платёж не задваивается (идемпотентность). |
| **B2B-гейтинг** | Обычный покупатель → 403 на B2B-доску и 404 на оптовый лот. Верифицированный дилер → доступ. Администратор → доступ. |
| **Заявка дилера** | Подача заявки → администратор одобряет → флаг `is_verified_dealer=True` → дилер получает доступ к оптовым лотам. |
| **Лимит платных API** | После превышения лимита запросов к реестру авто (Opendatabot) → сервер возвращает 429 Too Many Requests. |
| **Юридическое согласие** | Регистрация без галочки → 400. С галочкой → дата согласия записывается в базу. |
| **JWT-безопасность** | Выход из системы → refresh-токен отзывается и больше не работает. |
| **Тарифы Copart/IAAI** | 50 тиров сборов проверены формульно (Copart $5 000 broker → $504 total). |
| **Сборка фронтенда** | `npx tsc --noEmit` → 0 ошибок TypeScript. |

## Что владелец проверяет РУКАМИ перед запуском

### Оплата LiqPay в sandbox-режиме

Это единственное, что нельзя полностью проверить автотестом — нужен реальный LiqPay sandbox и публичный URL.

#### Шаг 1. Получить тестовые ключи LiqPay

1. Зайти на **liqpay.ua** → «Кабінет» → «Технічні налаштування» → «Тестовий режим».
2. Там будут два ключа:
   - **Public key** — начинается с `sandbox_i` (или похожее)
   - **Private key** — длинная строка
3. Сохранить оба ключа.

#### Шаг 2. Прописать в `.env` на сервере

```env
LIQPAY_PUBLIC_KEY=ваш_sandbox_public_key
LIQPAY_PRIVATE_KEY=ваш_sandbox_private_key
LIQPAY_SANDBOX=true
```

> ⚠️ Пока `LIQPAY_SANDBOX=true` — реальных денег не списывается. Переключить на `false` только после финальной проверки.

#### Шаг 3. Запустить сервер на публичном домене

LiqPay отправляет callback (уведомление об оплате) на ваш сервер. Он **не может достучаться до `localhost`** — нужен публичный адрес в интернете.

Варианты:
- **Вариант A (рекомендуется):** сразу деплоить на сервер (Railway, VPS) — тогда у вас будет публичный URL автоматически.
- **Вариант Б (для локальной проверки):** использовать `ngrok` — инструмент, который создаёт публичный туннель к вашему компьютеру.

**Как использовать ngrok для локального теста:**

```bash
# 1. Установить ngrok: https://ngrok.com/download
# 2. Запустить (пока работает Django на порту 8000):
ngrok http 8000
# 3. ngrok покажет URL вида https://abc123.ngrok.io
# 4. Прописать в .env:
# SERVER_URL=https://abc123.ngrok.io/api/v1/payments/liqpay/callback/
```

#### Шаг 4. Провести тестовую оплату

1. Создать листинг (или выбрать существующий).
2. Нажать кнопку оплаты → попадёте на страницу LiqPay.
3. Ввести **тестовую карту LiqPay:**
   - Номер: **4242 4242 4242 4242**
   - Срок действия: любая будущая дата (например, 12/26)
   - CVV: **любые 3 цифры** (например, 123)
4. Подтвердить оплату.

#### Шаг 5. Проверить результат

- В **личном кабинете LiqPay** → «Транзакції» должна появиться тестовая транзакция со статусом «Успішно».
- В **базе данных** (или в Django admin → Payments) платёж должен стать `completed`.
- Листинг, который оплачивали, должен сменить статус на `in_stock`.

#### Шаг 6. Переключение на боевые ключи (только после успешной проверки)

```env
LIQPAY_PUBLIC_KEY=ваш_боевой_public_key
LIQPAY_PRIVATE_KEY=ваш_боевой_private_key
LIQPAY_SANDBOX=false
```

> ⚠️ После этого — реальные деньги. Сначала убедитесь в sandbox.

## Что пока нельзя проверить автоматически до запуска

| Пункт | Статус | Что нужно |
|---|---|---|
| Живая оплата LiqPay через sandbox | ⚠️ **Нужна ручная проверка** | Sandbox-ключи + публичный URL (см. инструкцию выше) |
| Курс НБУ (обновляется ежедневно) | ⚠️ Celery + Redis | Настроить cron-задачу на сервере |
| Telegram-бот (уведомления) | ⚠️ Токен бота | Вставить `TELEGRAM_BOT_TOKEN` в `.env` |
| Opendatabot (реестр авто UA) | ⚠️ API-ключ | Купить ключ на opendatabot.ua |
| Импорт лотов с аукционов (Apify) | ⚠️ Apify-токен | Зарегистрироваться на apify.com |
| Юридические страницы | ⚠️ Юрист | Три шаблона готовы, нужна проверка юристом перед публикацией |
| Реальные тарифы фрахта | ⚠️ Брокер | UsLandRoute, OceanFreight, EuToUa — уточнить у брокера |
