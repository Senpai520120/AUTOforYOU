## 1. 3dicons (3D-иконки)

**Какой сайт настоящий.** `https://3dicons.co` — библиотека 3D-иконок (сайт сам говорит «open source & premium 3D Icons»). `https://3dicons.com` — **другой продукт**: «3D Icons 4000 by Iconshock», платный пак (4000+ иконок, 4K, Figma-файл). Для нас нужен `3dicons.co`.

**Что это, цена, лицензия.**
- Основная библиотека бесплатна («Download all»). Платный Pro — онлайн-редактор (цвет, угол, ремиксы) и расширенный экспорт.
- Pro на странице `https://3dicons.co/pro`: Free — $0; Pro — $99 разово (Lifetime), есть и Monthly (цена не указана). Pro: PNG до 4096 px (в Free до 800 px), премиум-материалы, свои текстуры, загрузка своих моделей FBX/GLB/GLTF. Оплата через Lemon Squeezy.
- Лицензия по данным сайта — CC0 (как сообщает FAQ-раздел сайта). Это значит: коммерческое использование без указания авторства. Но точной страницы лицензии и условий по AI-обучению и перепродаже я не нашёл; FAQ по ссылке из сайта (Notion) не удалось прочитать. Перед продакшеном — проверить лицензию вручную.
- Количество иконок на сайте противоречит себе: «1500+» в тексте и «200 icons» в футере. Уточнить.

**Форматы, вес, скорость.** Точных данных по SVG/PNG-размерам и весу файлов получить не удалось. Видно только WebP-превью и PNG-экспорт в Pro. Для страниц это важно так:
- 3D-иконка в PNG 512–1024 px обычно весит десятки–сотни КБ — для hero или карточек это заметно по LCP, если картинка большая и первая на экране.
- Правило: вставлять через `next/image` (WebP/AVIF, `sizes`, `priority` только для одной hero-картинки), маленькие размеры (64–128 px) для карточек, не тащить 4096 px в вёрстку.

**Чем полезен:** стилизованные 3D-иконки могут оживить пустые состояния, категории (кузов, двигатель, страна), блоки «как это работает» — вместо плоских иконок из Lucide.

**Риски:** вес и LCP; несогласованность стиля с остальным UI; «CC0» на слово не брать — проверить; при работе через Pro-экспорт — файлы не коммитить в git без оптимизации (лучше положить в `public/` уже в WebP/PNG сжатых размеров).

## 2. 21st.dev (каталог React/Tailwind-компонентов)

**Что это.** Каталог UI-компонентов для React + Tailwind + shadcn/ui: компоненты, шаблоны, темы shadcn, шейдеры, градиенты. Код **копируется** в проект, а не ставится как npm-зависимость.

**Цена.** Просмотр каталога бесплатен; бесплатно можно скопировать 2 компонента в день. Членство снимает лимит и открывает премиум-шаблоны. Отдельно — «21st AI» (генерация/доработка UI) с месячным лимитом кредитов. Точные цены — `https://21st.dev/pricing`.

**Лицензия.** На странице явного названия лицензии нет: сказано, что после установки код становится вашим и его можно менять. Перед коммерческим использованием — проверить условия на сайте и в каждом компоненте отдельно.

**Какие компоненты.** Упоминаются hero-секции, pricing, отзывы, кнопки, поля ввода, диалоги. Карточки, фильтры, тосты на странице не перечислены, но в каталоге `https://21st.dev/community/components` они, вероятно, есть — проверять там.

**Установка (shadcn-совместимо):**
- через shadcn CLI из registry-формата (`npx shadcn@latest add <url-компонента>`);
- через копирование промпта в AI-инструмент;
- инициализация MCP/CLI: `npx @21st-dev/cli@latest init --client claude` (см. `https://21st.dev/mcp.md`).

**Совместимость.** Заявлены Next.js, Vite, Remix, Astro; стек React + TypeScript + Tailwind. Для Tailwind 4 и Next 16 — проверять конкретный компонент (старые могут опираться на `tailwind.config.js` и `forwardRef`).

## 3. Storybook (каталог и тесты компонентов)

**Что это.** Инструмент для разработки и просмотра UI-компонентов отдельно от страниц. **Лицензия MIT** (проверено по LICENSE в репозитории `storybookjs/storybook`), бесплатно, open source. Актуальная мажорная версия по сайту — 10 (бейдж на главной показывал 9 — возможно, устаревший).

**Next.js.**
- Официальная страница (`https://storybook.js.org/docs/get-started/frameworks/nextjs`): минимум Next.js ≥ 14.1, Webpack 5. Next 15/16 на этой странице прямо не указаны — **перед внедрением проверить совместимость с Next 16 в changelog Storybook.**
- Рекомендуемый вариант — `@storybook/nextjs-vite` (автор пишет, что для большинства проектов лучше Vite; Webpack — только при кастомном Webpack/Babel).
- App Router поддерживается; компоненты с `next/navigation` требуют `nextjs.appDirectory: true` в `.storybook/preview.tsx`.
- Установка: `npm create storybook@latest`.

**Tailwind 4.** Страница упоминает PostCSS и импорт глобального CSS в `.storybook/preview.tsx` (`import '../app/globals.css'`). Версия Tailwind 4 не упоминается — конфиг Tailwind 4 (через `@import "tailwindcss"` в CSS) должен подхватиться так же, но проверить пробным запуском.

**Тесты.** На главной и в навигации: visual testing, interaction testing; визуальные тесты — через Chromatic (платный SaaS с бесплатным тарифом). Для a11y — аддон `@storybook/addon-a11y` (в документации раздел Addons; на главной не расписан). Vitest-интеграция — в документации Storybook; на главной не подтверждена.

## Как встроить в AUTOforYOU (на уровне идеи)

1. **21st.dev** — брать точечно: hero главной, блок тарифов/«пригон» (pricing), карточки объявлений, тосты. Компонент копировать через shadcn CLI в `frontend/components/ui`, затем адаптировать под наши токены и тексты (украинский). Каждую копию прогонять через Playwright (`@smoke` тест на страницу).
2. **Storybook** — завести отдельно от e2e: `npm create storybook@latest` с `nextjs-vite` во `frontend/`. Сначала — 5–10 базовых компонентов (кнопка, карточка объявления, поле ввода, тост). Stories используют тестовые данные из фабрик, не живой API (соответствует правилу «ни один тест не ходит в сеть»).
3. **a11y** — аддон a11y в Storybook для быстрой проверки контраста и ARIA; в Playwright — `@axe-core/playwright` на ключевых страницах (это отдельная проверка, Storybook её не заменяет).
4. **3dicons** — 3–5 иконок для пустых состояний и категорий, в WebP, размеры 128–256 px, через `next/image`. Перед этим — лицензия вручную.
5. Сначала — дизайн-токены в `globals.css` (Tailwind 4 `@theme`), потом компоненты. Иначе 21st-компоненты и Storybook будут выглядеть как разные проекты.

## Риски и ограничения

- **3dicons:** лицензия «CC0» со слов сайта, FAQ не удалось прочитать; несогласованные данные по количеству; вес PNG 4096 px убьёт LCP; `.com` — другой продукт, не путать.
- **21st.dev:** лицензия не названа явно; качество компонентов разное; лимит 2 копии в день на бесплатном тарифе; код может тянуть старые паттерны (`forwardRef`, `tailwind.config.js`) — проверять под Next 16 и Tailwind 4.
- **Storybook:** совместимость с Next 16 не подтверждена на странице; Chromatic — платный при большом объёме; поддержка Next требует внимательного чтения версий в changelog; установка добавляет зависимости во frontend (проверить размер `node_modules` и CI-время, учитывая дисковые ограничения).
- Общий риск: из-за сторонних компонентов и 3D-картинок можно получить визуальный хаос и тяжёлые страницы — ограничить набор и проверять Lighthouse/LCP.

## Итог (рекомендация)

- **Storybook (nextjs-vite) — да**, как каталог и а11y-проверка компонентов; сначала проверить совместимость с Next 16 пробной установкой в отдельной ветке.
- **21st.dev — да, точечно**: hero, pricing, карточки, тосты через shadcn CLI; лицензию и адаптацию под Tailwind 4 проверять на каждом компоненте.
- **3dicons — условно**: для 3–5 иконок в WebP-размерах; до этого вручную подтвердить CC0 и условия.
- Сначала — дизайн-токены и типографика, потом компоненты.
