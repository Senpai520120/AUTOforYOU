## 1. Refero Styles (styles.refero.design)

**Что это и как работает**
- Галерея «стилей» реальных сайтов: 2000+ дизайн-систем известных продуктов (Linear, Stripe, Notion, Vercel и др.), у каждой — цвета, типографика, отступы, компоненты и файл `DESIGN.md` (проверено).
- `DESIGN.md` — текстовое описание стиля, которое можно передать ИИ-инструменту (Cursor, Claude Code, Codex, v0, Lovable) (проверено).
- Есть MCP-подключение «Connect to your AI», чтобы ИИ «видел» референсы (проверено).
- Статус сервиса — Beta, новые стили добавляются еженедельно (проверено).
- Цены и условия лицензии на странице не найдены (проверено: на главной их нет). Бесплатность — не подтверждена, уточнить на сайте.

**Чем полезен AUTOforYOU**
- Референсы для шапки, главной, карточек объявлений, фильтров каталога, страницы авто, калькулятора, формы заявки. Например, смотреть страницы маркетплейсов и финтех-сервисов (Wise, Ramp, Mercury) на предмет структуры оплаты и цен.
- Палитра и типографика: быстро понять, какой «характер» бренда нужен (доверие и спокойствие для пригона, а не «кричащие» цвета).
- Мобильная версия: в галерее есть стили, но мобильные макеты надо смотреть отдельно.

**Как встроить**
- Не устанавливать ничего: это источник идей. Берём `DESIGN.md` выбранного стиля как бриф и переносим в наши токены (`:root` в `globals.css`, Tailwind 4 через `@theme`).
- Работать так: выбрать 2–3 референса, сверить скриншоты с нашими экранами, затем описать направление в `docs/design/` и передать в задачу implementer.

**Риски и ограничения**
- Лицензия: `DESIGN.md` описывает чужой бренд. Копировать логотипы, фото, шрифты брендов нельзя. Переносить можно только общие принципы (сетка, отступы, структура).
- Условия использования результатов не опубликованы в открытом виде, без проверки не использовать в коммерческом продукте напрямую.
- Beta: состав и доступ могут меняться.
- Тексты на галерее маркетинговые, по скриншотам трудно судить о качестве кода (кода нет, это описание).

## 2. shadcn/ui (ui.shadcn.com)

**Что это и как работает**
- Набор готовых React-компонентов (кнопка, диалог, таблица, карточка, форма, фильтры) на Radix UI и Tailwind CSS (проверено: сайт говорит «composable, accessible components»).
- Ключевая идея: CLI копирует исходный код компонентов в ваш проект (`components/ui/`), а не подключает библиотеку из npm. Вы владеете кодом (проверено по концепции сайта, «code you can customize»).
- Поддержка Next.js: есть шаблон `next` (проверено). Команда инициализации: `pnpm dlx shadcn@latest init -t next` (проверено, со вкладками npm/yarn/bun).
- Команда добавления компонентов: `npx shadcn@latest add button card dialog` (по памяти, проверить в docs).
- Лицензия: MIT (по памяти, проверить в репозитории GitHub). Бесплатно.

**Чем полезен AUTOforYOU**
- Готовая база для: шапка и меню (NavigationMenu, Sheet для мобильного меню), карточки объявлений (Card, Badge), фильтры каталога (Select, Slider, Checkbox, Tabs), калькулятор (Input, Slider, Tooltip, Table для разбивки стоимости), форма заявки (Form, Input, Textarea, Dialog), модалки подтверждения (AlertDialog).
- Мобильная версия: Sheet (выезжающая панель) для фильтров и меню — типичный паттерн для маркетплейсов.
- Единый стиль всех экранов вместо самописных кнопок и полей.

**Как встроить (на уровне идеи)**
1. Во `frontend/` (Next 16, Tailwind 4) выполнить `npx shadcn@latest init` в существующем проекте. Для существующего проекта в docs есть раздел «Existing Project» с ручными шагами — им и пользоваться, потому что шаблон `next` создаёт новый проект.
2. Установка компонентов по одному: `npx shadcn@latest add button card` и т.д. Файлы лягут в `frontend/components/ui/`.
3. Перед установкой сверить, что CLI не перетирает наш `globals.css` и существующие компоненты (сделать git-коммит до запуска).
4. Совместимость: shadcn давно поддерживает Tailwind 4 и CSS-переменные через `@theme inline`. Для Next 16 — проверить актуальную документацию через context7 (пока не делали).
5. Тесты: компоненты-копии в проекте — наш код, его покрывает обычный линтер и Playwright (`@smoke` / `@mobile`).

**Риски и ограничения**
- Все компоненты «одинаковые» — без доработки сайт будет похож на любой shadcn-проект. Выигрыш — в скорости, не в уникальности.
- Код компонентов становится нашим: обновления не придут автоматически, надо вручную обновлять через CLI.
- Radix UI и зависимости добавляют вес бандла; следить за размером страниц.
- Лицензия MIT: при копировании сохраняем уведомление (по памяти, проверить).

## 3. tweakcn (tweakcn.com)

**Что это и как работает**
- Визуальный редактор тем для shadcn/ui: меняете цвета, радиусы, шрифты, тени в живом предпросмотре, затем экспортируете код (проверено).
- Есть готовые пресеты (modern minimal, elegant luxury, neo brutalism, vintage paper, claude и др.) — проверено на главной.
- Экспорт: Tailwind CSS-конфиг/CSS-переменные, поддерживаются Tailwind v4 и v3, форматы OKLCH и HSL (проверено).
- Проверка контрастности (contrast checker) для WCAG — проверено.
- ИИ-генерация темы по картинке или тексту помечена как «Pro» (проверено). Тарифы: страница `/pricing` вернула пустой заголовок, цены не проверены.
- Открытый исходный код, на GitHub: `jnsahaj/tweakcn` (проверено, ссылка с главной). Главная пишет «No login required. Free to use. Open source.» (проверено).

**Чем полезен AUTOforYOU**
- Быстро подобрать палитру и радиусы под бренд (спокойный, доверительный стиль для пригона), вместо подбора цветов вручную.
- Проверка контраста: важно для продавцов и покупателей, особенно для текста цен и кнопок «Замовити».
- Пресеты-референсы: посмотреть, как выглядит один и тот же компонент в разных стилях.

**Как встроить**
1. Выбрать пресет на tweakcn, настроить цвета под наш фирменный цвет (Tailwind 4, OKLCH).
2. Скопировать CSS-переменные (блоки `:root` и `.dark`) в `frontend/app/globals.css`. Старые переменные не удалять сразу: сначала сравнить с текущими, затем заменить.
3. Проверить, что переменные используются в `@theme inline` (стандарт shadcn для Tailwind 4).
4. Визуально проверить главную, каталог, карточку авто и мобильный вид (Playwright-скриншоты или ручная проверка в браузере).

**Риски и ограничения**
- Пресеты тем — чужие палитры; некоторые могут совпадать с брендами (например, «twitter», «supabase», «claude» в названиях). Для своего бренда брать как основу и менять цвета.
- Тарифы Pro не проверены: если понадобится AI-генерация, уточнить цену на странице `/pricing`.
- Экспортируемый код — это только переменные и конфиг, не компоненты. Он не даёт готовых страниц.
- Не копировать код из сторонних «community»-тем без проверки лицензии.

## Итог и рекомендация

1. **shadcn/ui — основа редизайна.** Бесплатный, MIT, Next.js/Tailwind 4 совместимы, компоненты копируются в проект. Начать с `init` в существующем `frontend/` и с компонентов Button, Card, Sheet, Select, Form.
2. **tweakcn — подбор темы к shadcn.** Сделать палитру и проверить контраст до переноса в `globals.css`; это быстрее, чем подбирать цвета вручную.
3. **Refero — только как источник идей** для структуры экранов (каталог, карточка авто, калькулятор), без копирования брендовых элементов и без уверенности в лицензии.

Порядок: сначала tweakcn (выбрать тему), затем shadcn (компоненты и экраны), Refero — по ходу, для сверки структуры.
