# Ресурсы для редизайна: Mobbin, Fonts.com, Icônes

Дата исследования: 2026-11-21. Источники читались через WebFetch; где страница не открылась, это отмечено.
Код проекта не менялся.

## 1. Mobbin (https://mobbin.com)

**Что это.** Библиотека реальных экранов, потоков (flows) и UI-паттернов из мобильных и веб-приложений и сайтов.
По данным главной страницы: более 600 000 экранов, сервис работает с 2018 года, новые материалы добавляются еженедельно.
Источник: https://mobbin.com

**Бесплатно или платно.** Есть бесплатный аккаунт с ограниченным доступом. Полный доступ платный.
Тарифы по странице: Free, Pro (полная библиотека, поиск, потоки, анимации, MCP для одного пользователя),
Team (совместная работа, REST API), Enterprise (безопасность, администрирование, поддержка).
Цены на странице не видны: https://mobbin.com/pricing вернул HTTP 403, поэтому цены не проверены.

**Лицензия.** На главной странице явных условий лицензии нет. Сказано только, что примеры можно сохранять в коллекции
и копировать в Figma на подходящих тарифах, а в отчётах рекомендуется указывать ссылки на источники.
Перед коммерческим использованием паттернов нужно читать условия (Terms) на сайте: этого я не делал.

**Чем полезен для AUTOforYOU.** Это подсказки по структуре, а не готовый дизайн. Что смотреть:
- **Каталог / листинг автомобилей:** сетка карточек, фото-первый вид, переключение вид сетка/список.
- **Фильтры:** боковая панель или шторка на мобильном, чипы активных фильтров, диапазоны цены и года.
- **Карточка объявления:** галерея, ключевые характеристики в одном блоке, цена с валютой, CTA «Написати продавцю».
- **Онбординг и формы:** пошаговая подача объявления, прогресс-бар, пустые состояния.
- **Калькулятор / оформление заявки:** понятная разбивка стоимости (как у e-commerce чекаута).
- **Подписки и пейволлы:** если появятся платные тарифы для дилеров.
- **Навигация и хедер:** поиск сверху, быстрые фильтры, иконки разделов.

**Риски и ограничения.** Платный доступ к полной библиотеке; бесплатный уровень ограничен.
Лицензия на скопированные паттерны не ясна, поэтому брать можно идеи и структуру, а не картинки и тексты.

## 2. Fonts.com (https://www.fonts.com)

**Что это сейчас.** Сайт больше не продаёт шрифты напрямую. С 28 марта 2024 года шрифты перенесены на
MyFonts.com и в подписку Monotype Fonts. Страница fonts.com перенаправляет туда по смыслу.
Источник: https://www.fonts.com (контент читался через WebFetch).

**Бесплатно или платно.** Платно. Бесплатных шрифтов на сайте не описано; упомянут бесплатный доступ для агентств
с правом прототипирования, условия не раскрыты.

**Лицензирование веб-шрифтов.** На странице сказано только про «гибкие варианты лицензирования» для сайтов,
приложений и рекламы. Цены, лимиты по просмотрам и доменам там не указаны. Уточнять нужно на MyFonts / Monotype.

**Кириллица.** На странице информации нет. Для нашего проекта это критично, поэтому проверять перед покупкой
по конкретному шрифту на MyFonts (фильтр «Cyrillic» / список поддерживаемых языков).

**Сравнение с бесплатной альтернативой (Google Fonts + `next/font`).**
- Google Fonts бесплатны под SIL Open Font License, включая коммерческое использование и самохостинг.
- Многие шрифты имеют субсет `cyrillic`. В Next.js это `next/font/google` с `subsets: ['latin', 'cyrillic']`:
  шрифт скачивается на этапе сборки и отдаётся со своего домена, без запроса к Google в браузере пользователя.
- Для веб-проекта Google Fonts закрывает почти все потребности; платный Monotype даёт только узнаваемость бренда
  и редкие гарнитуры.

Кандидаты с кириллицей для проверки на fonts.google.com (по моим знаниям, не проверено в этом исследовании):
Inter, Manrope, Onest, Golos Text, PT Sans, Unbounded (для заголовков).

**Чем полезен.** Только если нужна платная гарнитура с подтверждённой кириллицей. Для редизайна достаточно Google Fonts.

## 3. Icônes (https://icones.js.org)

**Что это.** Поисковик иконок на базе Iconify (автор Anthony Fu, исходники: https://github.com/antfu/icones, лицензия MIT).
Позволяет искать иконки по всем наборам Iconify, смотреть их, копировать код и скачивать SVG.

**Что удалось проверить.** Главная страница icones.js.org в WebFetch отдала только заголовок (контент не загрузился).
Поэтому сведения взяты из репозитория GitHub и страницы коллекции Lucide (https://icones.js.org/collection/lucide),
которая тоже вернула лишь заголовок. Количество наборов и иконок на сайте не подтверждено.

**Бесплатно.** Да, сам инструмент бесплатный и открытый (MIT).

**Наборы иконок и их лицензии (проверено по источникам, где указано):**
- **Lucide:** лицензия ISC, бесплатно для коммерческого использования; более 1600 (README) / 2000+ (сайт) иконок.
  Форк Feather Icons. Источник: https://github.com/lucide-icons/lucide
- **Tabler, Phosphor, Material Symbols:** по моим знаниям, MIT (Tabler, Phosphor) и Apache 2.0 (Material Symbols).
  Здесь не проверено, перед использованием смотреть лицензию конкретного набора на iconify.design.

**Как подключать (проверено по https://github.com/unplugin/unplugin-icons):**
- Установка: `npm i -D unplugin-icons @iconify-json/lucide`. Пакет MIT.
- Импорт: `~icons/lucide/home`. Плагин в Vite/webpack; у Next.js с Turbopack (по умолчанию в Next 16) настройка другая,
  проверять отдельно.
- Варианты для нашего стека:
  1. **`lucide-react` (проще всего):** `npm i lucide-react`, `import { Car } from 'lucide-react'`. Tree-shaking, без плагинов.
  2. **`@iconify/react`:** доступ ко всем наборам по имени `<Icon icon="lucide:car" />`, но иконки подгружаются данными.
  3. **Копирование SVG с icones:** подходит для одной-двух иконок, но не масштабируется.

## 4. Как встроить в стек (Next.js 16, React, Tailwind 4, TypeScript)

- **Шрифты:** `next/font/google` в `app/layout.tsx` с `subsets: ['latin', 'cyrillic']`, переменная `--font-sans`,
  подключение в Tailwind 4 через `@theme` (`--font-sans: var(--font-...)`). Один шрифт для текста, при необходимости второй для заголовков.
- **Иконки:** `lucide-react` для всего UI; один размер и толщина линии (`strokeWidth`) на весь сайт.
- **Паттерны:** Mobbin используется как справочник. Переносим структуру (карточка, фильтры, форма), а стили и
  тексты пишем сами. Экраны копировать в код или макеты не нужно.
- **Проверка:** после подключения шрифта проверить кириллицу на странице (`npm run build`, затем визуально в браузере).

## 5. Риски и ограничения

- Mobbin: платный полный доступ, цены не проверены (403), условия использования паттернов нужно читать самому.
- Fonts.com: сайт переехал на MyFonts/Monotype, цены и лицензия веб-шрифтов не раскрыты, кириллица не подтверждена.
- Icônes: главная страница в WebFetch не загрузилась, список наборов взят из других источников.
- Лицензии: Lucide (ISC), unplugin-icons (MIT); лицензии других наборов проверять отдельно.
- Google Fonts и Lucide бесплатны, но для коммерческого проекта всё равно сохранить ссылку и текст лицензии в `docs/`.

## Рекомендация

1. Шрифты: Google Fonts через `next/font/google` с `cyrillic`. Monotype не покупать без явной нужды.
2. Иконки: `lucide-react` (ISC, простая интеграция, одинаковый стиль).
3. Структура страниц: смотреть на Mobbin (каталог, фильтры, карточка, формы) на бесплатном уровне; платную подписку
   брать только при необходимости регулярного поиска паттернов.
4. Перед внедрением сверить Cyrillic-поддержку выбранного шрифта на fonts.google.com и лицензии наборов.
5. Ссылки на источники: см. разделы выше; всё, что не удалось проверить, помечено.
