## Важное расхождение с ANSWERS.md (Q2): телефон для гостей

Владелец ответил на Q2: капча (Turnstile + honeypot) стоит «на показе телефона для гостей», то есть гость **может** увидеть телефон после антибот-проверки. В коде и задачах сделано наоборот: `LocalListingContactView` только для авторизованных (local_listings/views.py:364-378; на фронте «Увійдіть, щоб побачити телефон», LocalListingDetail.tsx:174), а задача 4.5 закрепляет «Аноним → 401» (4.5, блок «Тесты»), в 1.6 капча только на регистрации, заявке дилера и входе (1.6:52). Пункт F3.2 ниже. Решение основной сессии: либо внести в 1.6/4.5 гостевой режим показа (капча + IP-throttle + суточный лимит для гостей), либо подтвердить у владельца, что вход обязателен (он сильнее защищает от парсинга, но снижает конверсию).
