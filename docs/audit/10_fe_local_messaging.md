**Нужные Playwright-сценарии:**
1. Подача: успех (поля + 2 фото → экран «на модерации»). Ошибка: файл >8 МБ или .gif отклонён с понятным сообщением, 16-е фото недоступно.
2. Редактирование: сменить цену → телефон сохранился (регресс 10-Q1). Смена только телефона не отправляет на модерацию (10-Q3). Чужой пользователь получает 404/403 на `/local/<id>/edit`.
3. Страница объявления: в HTML-ответе (`page.request.get`) нет телефона и email. Аноним по кнопке уходит на `/login`. Авторизованный видит телефон.
4. Ошибки формы: антиспам (контакт в описании) показывает ошибку у поля `description`.
5. Фильтры: применить, получить URL с параметрами, перезагрузить, фильтры восстановлены. Проверить «назад».
6. Избранное: добавить → есть в `/me/favorites`. Аноним уходит на `/login`.
7. Сохранённый поиск: сохранить → есть в `/me/saved-searches`.
8. Жалоба: успех. Повторная жалоба показывает текст ошибки сервера (10-Q6).
9. Написать продавцу: ведёт на `/me/messages?conv=…`. Кнопка не видна владельцу.
10. Продвижение: выбор тарифа ведёт на URL `liqpay.ua/.../checkout` с суммой из тарифа. При `LIQPAY_SANDBOX=false` баннера нет.
