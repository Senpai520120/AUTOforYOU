## Як перевіряли

1. `npx modern-web-guidance legacy-scan` по `app/`, `components/`, `lib/` — 2 знахідки (обидві IME-Enter). Сканер покриває лише ~20% каталогу гайдів, тому далі ручний пошук.
2. `grep` по категоріях: діалоги, оверлеї, форми (`autoComplete`, `inputMode`, `type`), `dangerouslySetInnerHTML`, `target="_blank"`/`rel`, `localStorage`/`sessionStorage`, дати (`toLocale*`, `Intl`), зображення (`next/image`, `priority`, `fetchPriority`), dark mode, `@container`/`:has()`/anchor, застарілі API (`keyCode`, `unload`, `execCommand`), анімації.
3. Кожна знахідка звірена з гайдами `modern-web-guidance` (`dialog`, `light-dismiss-a-dialog`, `prevent-page-scroll-under-modal-dialog`, `forms`, `autofill-sign-up-form`, `ime-safe-enter-submit`, `dark-mode`, `optimize-image-priority`, `sanitize-untrusted-html`, `defer-rendering-heavy-content`, `branded-select-styling`, `motion`, `validate-input-after-interaction`, `menu`, `calculate-event-differentials`) і з документацією Next у `node_modules/next/dist/docs/`.

**Baseline** — позначка, з якого часу функція працює в усіх основних браузерах: *Widely available* — понад 2,5 роки, безпечно без запасного варіанту; *Newly available* — щойно у всіх, старі браузери ще трапляються; *Limited* — не всюди, потрібен fallback.

## Пропозиція для ROADMAP

Згрупувати в три задачі, решту лишити в беклозі.

1. **Задача «Нативна модалка `<dialog>`»** (п. 1, 14) — важливо. Переписати `components/ui/Modal.tsx` на `<dialog>` + `showModal()`, `closedby="any"` з fallback, блок прокрутки через `overscroll-behavior`. API компонента зберегти, щоб 6 місць використання не чіпати. Перевірка: наявні e2e модалок + axe. Заодно — `role` cookie-банера.
2. **Задача «Форматування чисел і дат через `lib/format.ts`»** (п. 3, 4, 5, 6) — важливо. Один модуль з `Intl.NumberFormat`/`Intl.DateTimeFormat` (`uk-UA`, `Europe/Kyiv`), заміна ~25 викликів. Перевірка: e2e-тест без hydration warning у консолі на `/local/<id>` і `/sellers/<id>`.
3. **Задача «Автофіл і клавіатура у формах»** (п. 7, 8, 9, 10, 11) — важливо для реєстрації (п. 7), решта бажано. `autocomplete`/`inputMode` у реєстрації, вході, формі дилера, оголошенні; IME-перевірка Enter; `type="text" inputMode="numeric"` для сум і пробігу (оновити e2e, що зараз печатають з клавіатури).
4. **Дрібна правка без окремої задачі** (п. 2): `priority` → `loading="eager"` + `fetchPriority="high"` у двох детальних сторінках — кілька рядків, можна в задачу 2 або окремим комітом.
5. **Беклог** (п. 12, 13, 15, 16, 17, 18): `:user-invalid`, popover для мобільного меню, `focus-visible`, reduced motion, `color-scheme`, `content-visibility`. Брати, коли буде задача про UI/доступність; dark mode — лише за рішенням власника.
