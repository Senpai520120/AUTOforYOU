## Контекст

Каркас (`integrations/base.py`, `integrations/registry.py`, `*_MODE`, страница «Статус інтеграцій», `IntegrationHealth`) появляется в задаче 3.1. Здесь четыре провайдера переводятся на него.

## Цель
**Общее**
- [ ] Все четыре провайдера — адаптеры на `BaseProvider` из 3.1. Режимы: `NBU_MODE`, `EMAIL_MODE`, `LIQPAY_MODE`, `TELEGRAM_MODE`. Статусы на странице 3.1 берутся из адаптеров и показывают последний успех и ошибку.
- [ ] На странице статуса есть кнопки проверки, которые не тратят платную квоту и не пишут пользователям:
  - «Оновити курс НБУ» — вызывает загрузку курса.
  - «Надіслати тестовий лист» — на email текущего админа.
  - «Перевірити бота» — `getMe` и `getWebhookInfo`.
  - Для LiqPay — только проверка конфигурации, без запросов к API.
