## Цель
- [ ] Общий компонент `Modal` (`role="dialog"`, `aria-modal="true"`, `aria-labelledby` на заголовок, закрытие по Esc и клику по подложке, фокус переходит внутрь при открытии и возвращается на кнопку-источник при закрытии, Tab не выходит за пределы окна). Все 5 модалок (PromoteModal, ReportButton, WriteSellerButton, SaveSearchButton, «продано» в `me/local-listings`) и `ConfirmDialog` из 6.2 используют его. Кнопка «×» имеет `aria-label="Закрити"`.
- [ ] Все `<label>` в login, register, trusted-shops, фильтрах `/ua` и `/listings`, форме объявления и калькуляторе связаны с полями (`htmlFor` + `id` через `useId()`); у полей без видимой подписи есть `aria-label`.
- [ ] Ошибки форм — `role="alert"`; ошибки полей связаны с полем через `aria-describedby`, поле с ошибкой — `aria-invalid="true"`.
- [ ] Звёзды оценки: `role="radiogroup"` с `aria-label="Оцінка"`, каждая звезда — `aria-label="N з 5"`, `aria-checked`.
- [ ] Иконочные кнопки («↻», колокольчик, чат) имеют текстовое имя (`aria-label`); декоративные эмодзи — `aria-hidden="true"`.
- [ ] axe (`@axe-core/playwright`) на `/login`, `/register`, `/me`, `/calculator`, `/local/new`, `/ua`, `/` — 0 нарушений уровня `serious`/`critical`.
- [ ] Опрос счётчиков в `Header` и треда в `/me/messages` приостанавливается, когда вкладка скрыта (`document.visibilityState !== 'visible'`), и делает немедленный запрос при возвращении на вкладку. Интервалы не меняются (не хардкодить новые числа без необходимости).
- [ ] Превью фото в форме объявления создаются один раз на файл (`useMemo`/`useEffect`) и освобождаются `URL.revokeObjectURL` при удалении фото и размонтировании.
- [ ] `DealCard` вынесен на уровень модуля (фокус в поле отзыва не теряется при вводе); `timeAgo` — в `frontend/lib/format.ts`, обе страницы используют его.
- [ ] Главная получает данные через `serverGet` (`lib/server-api.ts`) вместо своего fetch.
