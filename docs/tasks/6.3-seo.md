# Задача 6.3: SEO: sitemap, canonical, заголовки, robots/noindex

## Контекст
Базовые метаданные есть (`frontend/app/layout.tsx:10-29`: `metadataBase`, template `'%s | AUTOforYOU'`, OG `uk_UA`, `<html lang="uk">`), но sitemap неполная и расходится с canonical, robots не закрывает приватные разделы.

- **11-Q1 (важно):** `frontend/app/sitemap.ts:10-13,19` — берутся только `page=1` списков (`status=in_stock`, `status=in_transit`, `/local/listings/`). При `PAGE_SIZE: 20` (`core/settings.py:241`) в sitemap не больше ~60 карточек.
- **11-Q2 (важно)** (= 09-Q14): sitemap пишет лоты как `/listings/${listingSlug(l)}` (`sitemap.ts:45`, формат `42-toyota-camry-2020` — `frontend/lib/utils.ts:8-15`), карточки каталога ведут туда же (`frontend/components/listings/ListingCard.tsx:26`), а canonical страницы — `/listings/${id}` (`frontend/app/listings/[id]/page.tsx:43`). Sitemap состоит из неканонических URL, у одной страницы три адреса (`/listings/42`, `/listings/42-…`, любой мусорный хвост `/listings/42-abc` тоже отдаёт 200 — `parseInt` в `:29`).
- **11-Q3 (важно):** юр. страницы задают title с суффиксом — `privacy/page.tsx:5`, `terms/page.tsx:4`, `rules/page.tsx:5`, `refund/page.tsx:5`, `cookies/page.tsx:6` — и template из `layout.tsx:14` добавляет второй: «Політика конфіденційності | AUTOforYOU | AUTOforYOU».
- **11-Q4 (важно):** `frontend/app/robots.ts:11-12` (в аудите `:10-11`, строки сместились на одну) — `'/me/'`, `'/b2b/'` не закрывают сами `/me` и `/b2b`; `/local/new` и `/local/<id>/edit` не закрыты. `/b2b`, `/local/new`, `/dealers/apply` — client-страницы без своего layout с `robots`, наследуют `index: true` из `layout.tsx:25-28` (noindex есть только у `me/`, `login/`, `register/`, `calculator/` layout).
- Связанные желательные находки (включены):
  - **11-Q5:** `/calculator` в sitemap (`sitemap.ts:36`, в аудите `:27`) и в `allow` robots (`robots.ts:8`), но с `noindex` (`calculator/layout.tsx:6`) — противоречивые сигналы.
  - **11-Q6 / 10-Q11 (часть):** нет canonical у `/listings`, `/ua` (фильтры и пагинация дают дубли) и у `/local/[id]` (`frontend/app/local/[id]/page.tsx:20-35`); в title местного объявления цена без форматирования (`:26`), OG description — всё описание без ограничения длины (`:30`).
  - **11-Q8 (часть):** у 5 юр. страниц нет `description`.
  - **11-Q12:** ошибка backend при генерации sitemap молча даёт пустой список (`serverGet` → `null`, `sitemap.ts:14,20`; `lib/server-api.ts:35-38`).

## Цель
- [ ] Sitemap содержит **все** активные retail-лоты (`in_stock`, `in_transit`) и все активные местные объявления: генератор идёт по `next` до конца списка (с защитным потолком `SITEMAP_MAX_URLS` из `.env`, по умолчанию 45000 — ниже лимита протокола 50 000).
- [ ] Для лота один канонический URL — slug-формат `/listings/<id>-<make>-<model>-<year>` из `listingSlug`: он же в sitemap, в карточках, в `alternates.canonical` и `og:url`. Запрос `/listings/<id>` или `/listings/<id>-<неверный-хвост>` отвечает постоянным редиректом (308, `permanentRedirect`) на канонический.
- [ ] У `/local/[id]` есть `alternates.canonical` (`/local/<id>`), title с ценой в формате `toLocaleString('uk-UA')`, OG description обрезан до 160 символов.
- [ ] У `/listings` и `/ua` canonical на базовый путь без query; страницы с фильтрами (любой параметр, кроме `page`) — `robots: { index: false, follow: true }`. Для этого metadata делается через `generateMetadata({ searchParams })`.
- [ ] Title юр. страниц без ручного суффикса (template добавляет его один раз); у каждой есть `description` (≤ 160 символов).
- [ ] `robots.txt` закрывает `/me`, `/me/`, `/b2b`, `/dealers/`, `/local/new`, `/local/*/edit`, `/login`, `/register`, `/admin/`, `/api/`. **Ловушка:** правило `/me` без ограничения совпадает по префиксу с `/media/…` (фото объявлений) — использовать `'/me$'` и `'/me/'`, `'/b2b$'` и `'/b2b/'`; убедиться, что `/media/` не закрыт.
- [ ] `/b2b`, `/local/new`, `/local/[id]/edit`, `/dealers/apply` отдают `<meta name="robots" content="noindex">` (через серверные `layout.tsx` с `metadata.robots`).
- [ ] `/calculator` убран из sitemap и из `allow` в robots (пока калькулятор `noindex`); решение о снятии noindex после реальных тарифов — вне задачи.
- [ ] Если backend недоступен при генерации sitemap, ошибка логируется на сервере Next (`console.error`), sitemap отдаёт статические маршруты; `sitemap.ts` не кэширует пустой результат на час (`revalidate` для списков берётся только при успешном ответе либо `export const dynamic = 'force-dynamic'` + кэш на уровне fetch).
- [ ] Базовый URL сайта в `sitemap.ts`, `robots.ts`, `layout.tsx`, `listings/[id]/page.tsx` берётся из одного места (если 6.4 уже сделала `lib/site.ts` — из него; иначе создать `lib/site.ts` здесь, 6.4 его переиспользует).
- [ ] OG/Twitter-превью с картинкой у главной, `/calculator`, страницы лота (`/listings/[id]`) и местного объявления (`/local/[id]`): `og:title`, `og:description`, `og:url` (= canonical), `og:image` (абсолютный https-адрес, 1200×630, `og:image:alt`), `twitter:card=summary_large_image`. Картинка по умолчанию — для главной и калькулятора (общий «бренд» без цифр ставок); для лота и объявления — карточка-превью с маркой, моделью, годом, ценой (генерируется на сервере Next, `opengraph-image`/`ImageResponse`; шрифт с кириллицей кладётся в репозиторий, украинские буквы проверяются). Фото в превью — только если разрешено режимом фото (Q8): для лота при режиме `off` (по умолчанию) фото Copart/IAAI в `og:image` нет, превью генерируется без фото; при `partner`/`auction` — фото из `vehicles/photos.py::shareable_images` (2.11); для местного объявления — первое фото самого объявления, при отсутствии — генерируемая карточка. Превью открыто без авторизации (его запрашивают роботы Telegram, Instagram, TikTok).
- [ ] Страницы лотов и объявлений в статусе «Продано» остаются в sitemap и индексе, пока не истёк срок из настройки 4.3 (по умолчанию 90 дней), затем `noindex` ставит сама страница (4.3b); sitemap здесь только согласуется с ним (см. «Изменения после ANSWERS»).
