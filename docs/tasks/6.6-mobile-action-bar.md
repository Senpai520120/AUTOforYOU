# Задача 6.6: Нижняя панель действий на мобильной карточке («Подзвонити / Написати», «Розрахувати / Залишити заявку»)

> Источник: Н-46 (`docs/audit/39_PARITY_Q_R.md`, R2.2; решение владельца ANSWERS, шаг 9: Запуск; `docs/audit/32_NEW_TASKS_INDEX.md`). Волна: [ВОЛНА-1] для карточки лота; ветка C2C входит в код, но страницы `/local/*` до [ВОЛНА-2] скрыты, поэтому её проверка — после 4.5. Оценка: 1 сессия. Проверка security-reviewer: **обязательна** (показ телефона гостям).

## Контекст
- На карточке C2C-объявления телефон и «Написати» лежат в обычной вёрстке: `tel:` или кнопка «Показати телефон» (`frontend/app/local/[id]/LocalListingDetail.tsx:160-178`, состояние `phone`/`phoneLoading`/`phoneError` на `:32-34`, `handleShowPhone` на `:52-61`), `WriteSellerButton` (`:181-185`, условие `!isOwner && listing.status === 'active'`). Для владельца есть блок «Редагувати» (`:187-196`).
- Карточка лота (`frontend/components/listings/ListingDetail.tsx`, client): «Порахувати вартість» (ссылка на `/calculator?...`, `:108-114`) и `WriteSellerButton` (`:115`). Кнопку «Залишити заявку» и форму `LeadForm` добавляет 2.3.
- Фиксированной нижней панели нет нигде (`fixed bottom` встречается только у баннера cookie: `frontend/components/ui/CookieBanner.tsx:23-26`, `fixed bottom-0 inset-x-0 z-50`). Новая панель не должна его перекрывать и наоборот: новый посетитель из TikTok или Instagram видит баннер на первом экране, а панель — главный конверсионный элемент.
- Телефон гостю (решение Q2, задача 4.5): гость видит номер после капчи (Turnstile/honeypot) с суточным лимитом, кнопка «Показати телефон» разворачивает капчу, а не ведёт на `/login`. Компонент капчи — `frontend/components/ui/Captcha.tsx` (1.6). Панель обязана идти тем же путём, без отдельной реализации и без обхода капчи.
- 6.1 готовит мобильную вёрстку и оставляет нижний отступ у страницы лота; проекты Playwright `mobile-chrome` (Pixel 7) и `mobile-safari` (iPhone 13) добавляет 0.4.
- Собственные дневные счётчики и сигнальная точка для клика по панели — 8.7 (ключ `mobile_bar_click` и хелпер отправки). Аналитические события (3.5) — только после согласия.

## Цель
- [ ] Компонент `MobileActionBar` (client) на ширине `< md`, закреплён внизу экрана, учитывает `env(safe-area-inset-bottom)` на iPhone. На ширине `>= md` не рендерится.
- [ ] Карточка C2C-объявления (только если объявление `active` и пользователь не владелец): «Подзвонити» и «Написати». «Подзвонити»: если номер уже показан — ссылка `tel:`; если нет — запускает **тот же** сценарий показа телефона, что и блок на странице (для гостя капча, лимит, ошибки 429), после успеха кнопка превращается в `tel:`. «Написати» открывает тот же диалог `WriteSellerButton`.
- [ ] Карточка лота: «Розрахувати» (та же ссылка на калькулятор, что и сейчас) и «Залишити заявку» (тот же вход в форму `LeadForm` из 2.3, `source=listing`). Для проданных или недоступных лотов панель не показывается.
- [ ] Один источник правды: логика показа телефона и открытия формы заявки вынесена в общие хуки/пропсы, панель и обычные кнопки на странице используют их же; дублирующих запросов и двух капч нет.
- [ ] Не перекрывает баннер cookie: пока баннер виден, панель поднимается над ним (высота баннера пишется в CSS-переменную `--cookie-banner-h`, панель использует её для отступа); после выбора согласия панель опускается. Страница получает нижний отступ на высоту панели и safe-area, чтобы последний блок не пропадал под ней.
- [ ] Скрывается, пока пользователь вводит текст в поле (фокус в `input`/`textarea`/`select`: экранная клавиатура), и не перекрывает модальные окна (панель ниже по `z-index`, чем модалки).
- [ ] Доступность: кнопки минимум 44×44 px, подписи на украинском, `aria-label` у иконок, видимый фокус; панель не ловит фокус и не мешает навигации с клавиатуры.
- [ ] Клик по панели считается во внутренних счётчиках без ПДн (`mobile_bar_click`, 8.7); аналитическое событие уходит через `trackEvent` (3.5), только если есть согласие.

## Тесты
Django: серверной части нет, существующие тесты 4.5 (гость, капча, лимит) обязаны остаться зелёными; если `mobile_bar_click` принимается только через эндпоинт 8.7, его тест живёт там.
Playwright (`frontend/e2e/mobile-action-bar.spec.ts`, проекты `mobile-chrome` и `mobile-safari`; данные через `e2e_seed` из 0.4, Turnstile в e2e тестовыми ключами):
- Успех (лот): на `/listings/<slug>` панель видна внизу, «Розрахувати» открывает калькулятор с параметрами, «Залишити заявку» открывает форму 2.3; на десктопном проекте панели нет.
- Успех (C2C, после 4.5): гость жмёт «Подзвонити» → проходит капчу → кнопка стала `tel:` с номером; вошедший пользователь получает номер сразу; «Написати» открывает диалог.
- Успех (баннер): при невыбранном cookie-согласии панель стоит над баннером и обе кнопки кликабельны (не перекрыты); после выбора панель опускается к низу; последний блок страницы можно прокрутить выше панели.
- Ошибка/обход: капча не пройдена или лимит исчерпан (429) → номер не показан, понятная ошибка на украинском, повторная попытка без обхода; владелец своего объявления и неактивное объявление — панели нет; фокус в поле формы заявки → панель скрыта; открыта модалка → панель её не перекрывает; недоступный API счётчиков (`page.route` → 500) не мешает действию.
- Проверка доступности: кнопки не меньше 44 px по высоте, `axe` (из 6.5, если уже есть) без `serious`/`critical` на странице с панелью.
