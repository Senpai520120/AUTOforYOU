## Цель
- `/prigon` в шапке (десктоп и бургер) и в подвале, подпись `LANDING_INDEX_LABEL`, только если есть опубликованные лендинги (нет 404-ссылок и ссылок на пустую страницу).
- На главной блок «Популярні моделі» под «Як це працює» (ссылки на `/prigon/<slug>` и «Усі моделі» на `/prigon`), показывается только при непустом списке. Компонент общий с `/how-it-works`, разметка и `data-testid` прежние.
- На лендинге `/prigon/[slug]` — видимые хлебные крошки «Головна › Пригон авто з США › <марка модель>» (последняя без ссылки, `aria-current="page"`), построенные из тех же данных, что и существующий `breadcrumbLd`, чтобы HTML и JSON-LD не расходились.
- На лендинге — блок «Схожі моделі»: сначала другие опубликованные модели той же марки (`make`, без учёта регистра), затем остальные по порядку API, текущая страница исключена, не больше `SIMILAR_LANDINGS_LIMIT` штук. Если подходящих нет — блока нет. Признак «схожести» только `make` и порядок API (кузова и бюджета в публичных данных нет, поля не добавляем).
- Количество моделей — по одной константе в одном месте: `POPULAR_LANDINGS_LIMIT` (главная) и `SIMILAR_LANDINGS_LIMIT` (лендинг) в `frontend/lib/landings.ts`. Исходное значение предлагаю 6 для обеих (допущение исполнителя, не решение владельца).
- Главная: слово «пригон» в `title`, `h1` и description. Предложение (допущение, владелец может поправить текстом позже, задачу это не блокирует):
  - title: «AUTOforYOU — пригон авто з США під ключ»;
  - h1: «Пригон авто з США під ключ в Україну»;
  - description: «Пригон авто з аукціонів США Copart та IAAI під ключ: калькулятор вартості з розмитненням, доставка в Україну, каталог місцевих оголошень.» (≤ 160 символів, без цифр и обещаний цены).
  Формулировки не должны обещать точную цену (остаётся `is_estimate`).
- Данные всех трёх мест берутся тем же `getLandingList()` (кеш `LANDING_REVALIDATE_SECONDS`), страницы остаются `force-dynamic`, при `null` (API недоступно) блоки и пункты молча не показываются, страница не падает.

## Тесты
Django: изменений в backend нет, новых тестов не требуется; существующие тесты `landings` и API списка (порядок, фильтр опубликованных) должны остаться зелёными.
Playwright (`@smoke` там, где указано):
- Успех, `landing.spec.ts` `@smoke`: в шапке ссылка «Пригон авто з США» ведёт на `/prigon` (клик, URL, заголовок индекса); то же в подвале и в бургер-меню (`@mobile`).
- Успех, `landing.spec.ts` `@smoke`: на главной `popular-models` содержит `[E2E] Toyota Camry`, клик ведёт на `/prigon/<slug>`; черновик `e2e-draft` в блоке отсутствует (обход: прямой переход на черновик по-прежнему даёт 404).
- Успех: на лендинге крошки «Головна › Пригон авто з США › …» с правильными `href`, последняя без ссылки и с `aria-current`; количество и порядок элементов совпадают с `BreadcrumbList` из JSON-LD.
- Успех: «Схожі моделі» не содержит текущую модель, не длиннее `SIMILAR_LANDINGS_LIMIT`, при единственном опубликованном лендинге блока нет (если e2e-сид содержит один опубликованный лендинг — проверка идёт именно так; если несколько, проверить исключение текущей).
- `seo.spec.ts`: `title` главной содержит «пригон» (без учёта регистра) и «AUTOforYOU» ровно один раз, `h1` содержит «пригон», `meta[name=description]` содержит «пригон» и не длиннее 160 символов.
- Ошибка/обход, пустой справочник: серверный рендер Next не перехватывается `page.route`, поэтому проверка «нет пункта в шапке и блока на главной при пустом списке» в e2e недоступна без стека без опубликованных лендингов: поставить `test.fixme('LAND-2 → пункт «Пригон» и блок «Популярні моделі» скрыты при пустом справочнике (нужен стек без опубликованных лендингов)')`, рядом с `LAND-1`. - Мутации: убрать `hasLandings` из шапки, убрать исключение текущего slug, убрать слово «пригон» из title — соответствующие тесты красные.
