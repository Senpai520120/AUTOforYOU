## Тесты
Django:
- `test_env_templates.py`: множество переменных из кода ⊆ ключи `.env.example`; то же для `.env.docker.example` (с явным списком допустимых исключений, например прод-только переменные TLS); `process.env.*` фронтенда ⊆ ключи `frontend/.env.example`. Удаление любой переменной из шаблона → тест падает (проверено вручную один раз).

- `launch_check`: при пустых обязательных переменных (`override_settings`/мок env) → код ≠ 0 и в выводе имена переменных; при заполненных (фиктивные значения) и активных тарифах из фикстур → код 0; команда не выполняет записей в БД (`assertNumQueries` только на SELECT или проверка через `CaptureQueriesContext`).
- Проверка ссылок `docs/LAUNCH_CHECKLIST.md`: каждый путь вида `` `что-то/файл.ext` `` существует в репозитории.
- `.env.example`: `ANTISPAM_MODE=hard` (прод-шаблон, решение шага 7), `PAYMENTS_ENABLED=false`, `TURNSTILE_SECRET_KEY` присутствует пустым; в `.env.docker.example` (dev) `ANTISPAM_MODE=soft`.
