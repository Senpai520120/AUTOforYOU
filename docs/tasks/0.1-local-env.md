## Шаги
1. Проверить исходное состояние: `git config core.autocrlf`, `git ls-files --eol`. Записать вывод в план сессии.
2. Создать `.gitattributes`:
   ```
   * text=auto
   *.sh text eol=lf
   docker/* text eol=lf
   Dockerfile* text eol=lf
   nginx/*.conf text eol=lf
   *.png binary
   *.jpg binary
   ```
   Затем выполнить `git add --renormalize .` и проверить `git status`: должны измениться только файлы с переводом строк. Рабочие копии с CRLF обновить точечно, для двух файлов: `git checkout -- docker/entrypoint.sh deploy.sh`. Массовые `git reset --hard` и `git rm --cached -r .` без согласования не использовать. Коммит: `chore: .gitattributes — LF для shell-скриптов (12-Q14)`.
3. В `Dockerfile.backend` перед `chmod` добавить `sed -i 's/\r$//' /app/docker/*.sh`.
4. В `ci-cd.yml`, джоба `backend`, добавить шаг «Shell scripts use LF»: `git ls-files --eol -- '*.sh' | awk '$1 != "i/lf" {print; bad=1} END {exit bad}'` и ещё `! grep -lU $'\r' $(git ls-files '*.sh')`.
5. На Windows: `docker compose down` (разрешено владельцем, ANSWERS «Docker-стек после аудита»), затем `docker compose up -d --build`, `docker compose ps`. Дождаться `(healthy)`, потом `cd frontend && npx playwright test`. Результат записать в `PROGRESS.md`.
6. Удалить локальный `venv/` (разрешено владельцем; перед удалением убедиться, что команда тестов работает через `.venv`: `scripts/test-backend.ps1`). В README записать «рабочее окружение — `.venv`», а в PyCharm выбрать интерпретатор `.venv\Scripts\python.exe` (пункт для владельца, код не меняется).
7. Написать `scripts/test-backend.ps1`:
   ```powershell
   $env:DATABASE_URL=''; $env:REDIS_URL=''
   & "$PSScriptRoot\..\.venv\Scripts\python.exe" manage.py test @args
   ```
   И `scripts/test-backend.sh`: `DATABASE_URL= REDIS_URL= "$(dirname "$0")/../.venv/…/python" manage.py test "$@"`, путь к python для Windows и Linux выбрать через проверку существования. Скрипт падает с понятным сообщением, если `.venv` нет.
8. Обновить `README.md` и `docs/BACKEND_TESTS.md`: команда тестов, объяснение про `.env`-шаблон с хостами `db`/`redis`, упоминание Playwright только из `frontend/`. Остальные расхождения документов (13-Q19) правит задача 0.6.
9. Прогнать все проверки из «Готово, когда».
