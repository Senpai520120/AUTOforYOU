# Задача 11.13: Дизайн-система (shadcn/ui, токены, шрифт, иконки)

Модель: Sonnet (implementer). security-reviewer не обязателен (нет ПДн, платежей, прав). Обязателен скилл `modern-web-guidance`; гайды уже в `.mwg/`: color, dark-mode, typography, visually-stable-font-fallbacks, icons — прочитать до начала.

## Контекст
Источники: `docs/SPEC_IMPORT_CATALOG_2026-11.md` (модуль H), `ROADMAP.md` 11.13, `docs/design/research/01_refero_shadcn_tweakcn.md` и `02_mobbin_fonts_icones.md` (разделы «Итог/Рекомендация»).
- Свои компоненты лежат в `frontend/components/ui/` (PascalCase: `Badge.tsx`, `Skeleton.tsx`, `Modal.tsx`…). Windows не различает регистр: shadcn-файл `badge.tsx` в той же папке столкнётся с `Badge.tsx`.
- В `frontend/app/globals.css` в `:root` свои переменные `--bg`, `--surface`, `--primary`, `--muted`, `--border`, `--text`, `--accent`, `--danger`. Имена пересекаются с токенами shadcn.
- Фокус: поведение 10.28 (видимый `focus-visible` на всех интерактивных элементах) нельзя потерять.
- Страницы пока на хардкод-классах `slate-*`/`blue-*` (их переводит 11.14).
- Решение оркестратора: токены задаём сами (без GUI tweakcn), контраст проверяем расчётом.

## Цель
- shadcn/ui подключён через CLI (`npx shadcn@latest init`), Tailwind 4, `cssVariables: true`, `iconLibrary: lucide`, поле `tailwind.config` в `components.json` пустое. Алиас `ui` -> `@/components/shadcn` (НЕ `@/components/ui`). Утилита `cn` в `frontend/lib/utils.ts`.
- Компоненты в `frontend/components/shadcn/`: button, card, input, label, textarea, select, badge, separator, sheet, skeleton, tabs.
- Тема в `frontend/app/globals.css` в формате shadcn: OKLCH-токены `:root` и `.dark`, `@theme inline`. Primary — глубокий синий; accent — янтарный (бренд, #f59e0b); нейтральные — slate; destructive — красный; плюс `--success` и `--warning` с парами foreground. Радиус ~0.625rem.
- Контраст: текст >= 4.5:1, границы полей и значимых элементов >= 3:1 (WCAG 1.4.3 / 1.4.11). Пары посчитаны и записаны в документ.
- Тёмная тема: токены `.dark` определены, но НЕ включены (нет класса/медиа-переключения); `:root { color-scheme: light }` задан явно. Включение — решение 11.14.
- Шрифт Manrope через `next/font/google`: `subsets: ['latin','cyrillic']`, `display: 'swap'`, `adjustFontFallback` (по умолчанию включён, не отключать), переменная -> `--font-sans` в `@theme`. Без CLS при подмене.
- Старые переменные (`--bg`, `--surface`, `--primary`, `--muted`, `--border`, `--text`, `--accent`, `--danger`): найти все использования (Grep по `var(--…)` и CSS-модулям), перевести на новые токены, старые удалить.
- Глобальный фокус через `--ring`; поведение 10.28 сохранено; есть `@media (forced-colors: active)` для фокуса.
- Header, Footer, MobileNav переведены на токены и компоненты shadcn; иконки — `lucide-react`, одна толщина линии (`strokeWidth` общий).
- Документ `docs/design/DESIGN_SYSTEM.md`: токены, таблица пар контраста с рассчитанными значениями, шрифт, иконки, правила (что брать из `components/shadcn`, когда оставлять свои из `components/ui`), лицензии со ссылками: shadcn/ui (MIT), lucide (ISC), Manrope (OFL).
