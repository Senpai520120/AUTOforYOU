# Задача 9.58: `scripts/e2e-run` и флаг `E2E_RELAX_THROTTLES` (M13) 🔒

## Контекст
Локальный e2e-прогон падал на 429 (`lead`, `metrics`, `mobile`): локальный `.env.e2e` — разовая копия шаблона и молча устаревает, а лимиты ослаблялись набором из 12 переменных `THROTTLE_*_RATE`, причём часть лимитов (метрики, контакты, сообщения, Telegram-ссылка) не ослаблялась вовсе. Порядок прогона (остановить dev-стек без `-v`, поднять e2e-стек, `FLUSHALL`, seed, cleanup, вернуть dev-стек) делался руками (`docs/BRAINSTORM_2026-11.md`, §8.9, M13).

## Цель
- `scripts/e2e-run.sh` (и обёртка `scripts/e2e-run.ps1`): одна команда. Сверяет ключи `.env.e2e` с `.env.e2e.example` (печатает только имена недостающих ключей, не значения), останавливает dev-стек `docker compose down` **без `-v`**, поднимает e2e-стек, ждёт healthy, `FLUSHALL`, `e2e_seed`, запускает Playwright с вашими аргументами (`E2E_PASSWORD` из `.env.e2e`, не печатается), затем всегда `scripts/e2e-cleanup.sh` и `docker compose up -d --scale bot=0`. Код возврата = код Playwright.
- Флаг `E2E_RELAX_THROTTLES`: один вместо набора `THROTTLE_*_RATE`; действует только при `E2E_SEED_ALLOWED=true`; не трогает блокировку входа (`LOGIN_*`) и лимит `client_errors` (его реальный 429 проверяет `error-monitoring.spec.ts`); `launch_check` на сервере сообщает об ошибке; в `.env.example` и `.env.docker.example` флаг выключен.

**Остаток:** локальные retries не включаются (решение штурма). Предложение правки `CLAUDE.md` (раздел E2E: «запуск — `scripts/e2e-run.ps1`») записано в отчёт, файл не менялся без согласия владельца.

## Шаги
1. `core/throttle_relax.py`: чистые функции; подключение в `settings.py`; ошибка в `launch_check`.
2. Шаблоны: `E2E_RELAX_THROTTLES=true` в `.env.e2e.example` вместо 12 переменных; закомментированный `# E2E_RELAX_THROTTLES=false` в боевых шаблонах.
3. Скрипты и shell-тест; раздел `shell-tests` в `check-infra.sh`.
4. Обкатка: набор `@smoke` и набор `lead`, `metrics`, `mobile`; раздел E2E в `README.md`.
