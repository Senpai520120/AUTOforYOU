# Задача 10.25: Подача объявления — вход, кнопка и срок, подсказка телефона, капча из нижней панели

## Контекст
Источник: `docs/audit/41_REVIEW_2026-11-11.md`, находки B4–B6, B10. `/login?next=/local/new` показывал голую форму входа без причины (`frontend/app/login/page.tsx`); `/register` вообще не знал про `next`. Кнопка формы `frontend/components/local/LocalListingForm.tsx` называлась «Опублікувати оголошення», хотя объявление уходит на модерацию, срока нет. Подсказка телефона («Показується тільки авторизованим покупцям») не соответствовала 10.23: номер берётся сервером из подтверждённого (`local_listings/phone.py`). Нижняя панель карточки (`MobileActionBar`) для гостя открывает капчу в блоке `#phone-block` (`usePhoneReveal`), фокус при этом не ставился. Страница `/sellers/[id]` проверена: API без телефона/email (`SellerPublicView`), несуществующий/без объявлений — 404 API и мягкая страница «Продавця не знайдено».

## Цель
- `/login?next=/local/new` и `/register?next=/local/new`: над формой «Щоб подати оголошення, увійдіть або зареєструйтесь. Реєстрація безкоштовна.»; `next` проходит через `safeNext`, чужой `next` и его отсутствие — без пояснения; ссылки вход↔регистрация сохраняют `next`.
- Кнопка новой подачи — «Надіслати на модерацію»; рядом «Орієнтовний строк модерації — до N год.» из `SiteSettings.listing_moderation_hours`; пусто — строка не показывается.
- Подсказка телефона: подтверждён — «Номер з вашого підтвердженого Telegram… /unlink… розділ «Telegram» кабінету»; не подтверждён (admin/режим без проверки) — как подтвердить, ссылка `/me/telegram`.
- Ошибки формы: фокус на первое невалидное поле (`focusFirstInvalid`).
- Нижняя панель карточки: «Подзвонити» у гостя прокручивает к блоку капчи и ставит на него фокус.
- `/sellers/[id]`: без ПДн, axe-прогон в `a11y.spec.ts`.
- API: `GET /api/v1/site-settings/` получает необязательное `listing_moderation_hours` (число или null, только чтение).
