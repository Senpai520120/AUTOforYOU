## Цель
- [ ] **Длина описания (B5.1).** `LOCAL_LISTING_DESCRIPTION_MAX` (`.env`); превышение → 400 с ошибкой у `description` (создание и правка). Значение по умолчанию подбирается так, чтобы готовый пост 5.2 (заголовок + описание + ссылка) помещался в 4096 символов; помечено `# ПРОВЕРИТЬ`. Значение приходит фронту из `/local/config/` (4.2) как `description_max`; в форме счётчик «N / max».
- [ ] **Антиспам (B5.2).** В `antispam.py`: отдельное правило `email` (в `detect_contacts` тип `'email'`); границы слов для `tg`, `viber`, `signal` и т. п. (без срабатывания на «потужний», «ватсапп» внутри слов и т. п.); подборка тестовых строк ложных срабатываний в тестах. Регулярные выражения остаются в коде; список стоп-слов в админке — Рост (9.3). Сообщения об ошибках — украинские, указывают тип найденного контакта.
- [ ] **Лимит подачи (B7.2).** Throttle на `POST /api/v1/local/listings/` (только создание, GET каталога не затрагивается): два scope — `listing_create` (в час, `THROTTLE_LISTING_CREATE_RATE`) и `listing_create_daily` (в сутки, `THROTTLE_LISTING_CREATE_DAILY_RATE`). Значения по умолчанию заводит исполнитель как рабочие, помечены `# ПРОВЕРИТЬ`, владелец подтверждает. Превышение → 429 с текстом «Забагато нових оголошень. Спробуйте пізніше» и заголовком `Retry-After`. Для staff лимит не действует.
- [ ] **Правило о запрещённом контенте (N6.1).** В `frontend/app/rules/page.tsx` в «Що забороняється» добавлены пункты: оголошення про авто, що перебуває в розшуку; про авто в заставі або під арештом без згоди заставодержателя; про авто без документів, що підтверджують право розпорядження. Текст — черновик Claude на украинском, в коде комментарий `// ПРОВЕРИТЬ С ЮРИСТОМ`; пока `legal_docs_approved=false` страница показывает плашку «Шаблон» (1.12).
- [ ] **Чекбокс при подаче (N6.1).** Обязательный чекбокс «Авто не в розшуку, не в заставі, документи в наявності» (отдельно от согласия с правилами). Поля модели `legal_confirmed` (`BooleanField`, default `False`) и `legal_confirmed_at`; в create-сериализаторе `legal_confirmed = BooleanField(write_only=True)`: без отметки → 400 `{"legal_confirmed": ["Підтвердіть, що авто не в розшуку, не в заставі, документи в наявності."]}`. При правке не требуется. Значение и время пишутся рядом с `agreed_to_rules_at`. Ссылка на пункт правил рядом с чекбоксом.
- [ ] Кнопка «Надіслати» неактивна, пока обе отметки не поставлены; ошибка с сервера выводится у чекбокса (механизм вывода ошибок — 4.2).

## Шаги
1. Тесты-сначала (см. «Тесты»).
2. `antispam.py`: `_EMAIL_RE`, границы слов; тип `'email'` в `detect_contacts`; сообщения ошибок в сериализаторах учитывают типы.

4. `local_listings/throttles.py`: подкласс `ScopedRateThrottle`, `allow_request` пропускает всё, кроме `POST`, и staff; scope задаются во view (`throttle_classes` со scope по классу). Ставки в `REST_FRAMEWORK['DEFAULT_THROTTLE_RATES']` из `.env` (рядом с `contact`, `core/settings.py:237-238`).
5. Валидаторы длины и `legal_confirmed` в сериализаторах; `description_max` в `/local/config/`.
6. Фронт: счётчик длины, чекбокс, блокировка кнопки, пункты правил.

## Тесты
Django (`local_listings/tests.py`; кэш throttle очищать в `setUp`, см. 0.2):
- Описание длины `max` → 201; `max + 1` → 400 `description` (`override_settings`); то же в PATCH.
- Антиспам (`ANTISPAM_MODE=hard`): `ivan@mail.ua`, `ivan@gmail.com` → 400 с типом email; «потужний мотор», «ватсапп» как часть слова и обычные годы/пробег/цена/объём — не срабатывают; `tg: @seller`, `Viber 099…`, `t.me/x` — срабатывают. В `soft` — запись создаётся с `has_contact_in_text=True`. В `off` ничего не ловится.
- Throttle: `listing_create='2/hour'` → третий POST 429 с `Retry-After`; GET каталога не ограничен при тех же настройках; `listing_create_daily='3/day'` при большом почасовом → четвёртый POST 429; staff не ограничен; ограничение per-user (другой пользователь проходит).
- Чекбокс: POST без `legal_confirmed` и с `false` → 400 `legal_confirmed`, объявление не создано; с `true` → 201, `legal_confirmed=True`, `legal_confirmed_at` заполнено; PATCH без поля → 200.
- Старые объявления (без `legal_confirmed`) остаются в каталоге.

Playwright (`frontend/e2e/c2c-submission-limits.spec.ts`; storageState продавца из 0.4):
- Успех: на `/local/new` заполнить форму, отметить оба чекбокса, ввести описание в пределах лимита → экран «Оголошення надіслано на модерацію».
- Ошибка/обход: без чекбокса «Авто не в розшуку…» кнопка «Надіслати» неактивна; обход через `request.post` без `legal_confirmed` → 400; описание длиннее лимита из `/local/config/` → ошибка под полем, счётчик красный; e-mail в описании при `ANTISPAM_MODE=hard` (e2e-стек) → ошибка у поля «Опис»; e2e-стек с `THROTTLE_LISTING_CREATE_RATE=2/hour`: третья подача → сообщение «Забагато нових оголошень…»; `/rules` содержит новые пункты про розшук и заставу.
