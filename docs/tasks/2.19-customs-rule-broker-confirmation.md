# Задача 2.19: Правило розмитнення — зсув віку авто и митна вартість зі зборами аукціону (решение брокера)

Источник: проверка владельцем двух лотов Copart 2026-11-08 (dev, демо-тарифы). Лот 63561446: 2015 GMC Acadia SLE, 3564 см³, бензин → $4213 / 477 986 грн. Лот 67506716: 2013 Ford Fusion SE, 2488 см³, бензин → $9347 / 618 729 грн.

## Контекст
- `pricing/calculator.py:180` `calc_age_coeff` = `год_расчёта − год_выпуска − offset_years`, `offset_years` — `CustomsCalcRule.age_offset_years` (по умолчанию 0; поле в `pricing/models.py:463`, админка `pricing/admin.py:135`). Для 2015 в 2026 получается 11, для 2013 — 13. По распространённой трактовке ПКУ ст. 215.3.1 (полные календарные годы) — 10 и 12. Разница: GMC ≈ €356 акциза (~25 тыс. грн с НДС), Ford ≈ €124. Трактовку я не утверждаю: решает брокер.
- Таможенная стоимость (`calculator.py:223-226`) = цена лота + US land + ocean (+ EU→UA по `customs_value_includes_eu_to_ua`). Аукционные сборы ($288 и $538 в примерах) в неё не входят — вопрос брокеру.
- Флаги правила уже данные (`CustomsCalcRule`, задача 2.5), отметка `confirmed_by_broker` и `confirmed_at` есть. Хардкода ставок быть не должно.
- Пункт «Правило розмитнення» уже есть в `docs/LAUNCH_CHECKLIST.md` (стр. 492); здесь он уточняется.
