- Очередь и уведомления модерации по жалобам — 4.5b; журнал аудита экшенов — 1.13. Здесь только входной API.

## Тесты
Django (мутацией):
- **B8:** аноним → 401; пользователь с неподтверждённым email → 403; 11-я жалоба за час (по `override_settings` лимита `2/hour` → 3-я) → 429; `comment` длиннее лимита → 400, не сохранён.
- **B9:** жалоба на чужое `pending`/`hidden`/`rejected` и на несуществующий id — один и тот же статус и тело (404, одинаковый `detail`); на `ACTIVE` → 201; `reported_user=<чужой id>` не влияет на `Report.reported_user` (или 400); жалоба на своё объявление — запрещена (400) либо принимается по прежним правилам — зафиксировать тестом.
- Матрица 401/403/404 в `tests/test_authz_matrix.py` включает `reports`.
Playwright: успех — пользователь с подтверждённым email жалуется на активное объявление (при `C2C_ENABLED=true`), видит «Скаргу надіслано»; ошибка/обход — 11-я жалоба подряд (или лимит e2e-стека) показывает текст «Забагато запитів, спробуйте пізніше»; прямой `POST` на скрытое объявление через `request` → 404, как для несуществующего.
