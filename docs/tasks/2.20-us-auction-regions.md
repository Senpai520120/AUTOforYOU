# Задача 2.20: Площадки Copart/IAAI по штатам: доставка по США зависит от региона

Источник: проверка владельцем 2026-11-08: лот в Glassboro West (NJ, рядом с портом New Jersey) и лот St. Cloud (MN) получили одинаковую доставку по США ($800).

## Контекст
- `options.auction_locations` строится в `pricing/calculator.py:722-740` из `USLandRoute` (`auction_location` → `us_port`); в данных только `california` и `general`. Любая площадка вне Калифорнии = `general`.
- Тарифы доставки — данные админки (`USLandRoute`), хардкода нет. Нет справочника «площадка → штат → регион».
- Фронт: форма `/calculator` выбирает `auction_location` из справочника. В данных лота (импорт) штат/площадка есть не всегда.

## Цель
- [ ] Справочник площадок: `AuctionYard` (аукцион, название, штат, регион, `is_active`) или связка «штат → регион» — вариант выбрать в шаге 1 по объёму данных; регион (`auction_location` в `USLandRoute`) остаётся ключом тарифа, штат лишь сопоставляется с регионом.
- [ ] Тарифы «регион → порт США» заводятся в админке (`USLandRoute`); несколько регионов вместо двух. Цифры не придумываются: источник — прайс экспедитора (вопрос владельцу).
- [ ] В форме калькулятора выбор штата (или площадки), регион определяется автоматически; подсказка про ближайший порт. Тексты на украинском.
- [ ] Если для штата нет тарифа — честное сообщение, а не `general` по умолчанию. Исключение (общий тариф «решта США») — только если владелец его явно завёл в данных.
- [ ] `GET /pricing/rates/` отдаёт штаты/регионы; `Calculation` хранит в снимке и штат, и регион.

## Тесты
Django: лот NJ и лот MN дают разную доставку при разных тарифах; штат без тарифа → 400 с понятным текстом; неактивный двор/регион не в справочнике; снимок содержит штат и регион; обратная совместимость: старые `california`/`general` работают.
Playwright: успех — выбрать NJ и MN, итог отличается; ошибка/обход — выбрать штат без тарифа: сообщение, расчёта нет, запрос расчёта не отправлен (`helpers/network.ts`).
