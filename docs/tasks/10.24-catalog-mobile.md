# Задача 10.24: Каталог /ua на мобильном — фильтры, цена «≈ $», пустой результат

## Контекст
Источник: `docs/audit/41_REVIEW_2026-11-11.md`, находки B2, B3, B8. Форма фильтров `frontend/components/local/LocalListingFilters.tsx` на 375 px занимала несколько экранов до первой карточки. Карточка `LocalListingCard.tsx` показывала только `price currency` (UAH/EUR без ориентира в долларах). Пустой результат в `app/ua/LocalCatalogGrid.tsx` - только текст «Спробуйте змінити фільтри», без сброса и пути к калькулятору. `price_usd` есть в модели (`local_listings/models.py`, 6.7), но не в `LocalListingListSerializer`.

## Цель
- До 768 px фильтры свёрнуты за кнопкой «Фільтри (N)» с `aria-expanded`/`aria-controls`; N = число непустых параметров фильтра в URL (`countActiveFilters`, `lib/local-filters.ts`; `page` и `ordering` не считаются). От 768 px блок виден как раньше. После «Застосувати»/«Скинути» блок сворачивается.
- Карточка: основная цена в валюте объявления, рядом «≈ $N» по `price_usd` через `formatUsd`; для USD или без `price_usd` - без дубля.
- Пустой результат: `EmptyState`, при активных фильтрах - ссылка-кнопка «Скинути фільтри» (`/ua`), всегда - «Порахувати пригон з США» (`/calculator`).
- API: `price_usd` в публичном списке и детали (только чтение).

## Файлы
Изменить: `local_listings/serializers.py`, `openapi.yaml` (вручную, 3 схемы: List/Detail/Owner), `frontend/components/local/LocalListingFilters.tsx`, `frontend/components/local/LocalListingCard.tsx`, `frontend/app/ua/LocalCatalogGrid.tsx`, `frontend/lib/types.ts`, `users/management/commands/e2e_seed.py`, `ROADMAP.md`, `PROGRESS.md`.
Создать: `frontend/lib/local-filters.ts`, `frontend/e2e/catalog-mobile.spec.ts`, `local_listings/tests_price_usd.py`, этот файл.
Не трогать: `cars/`, `frontend/e2e/test-1.spec.ts`, миграции.

## Шаги
1. `price_usd` в сериализатор списка (наследует деталь/кабинет), схема API.
2. `countActiveFilters` и свёртка фильтров.
3. «≈ $» на карточке, `EmptyState` в сетке.
4. Сид `[E2E]` объявления в UAH с `price_usd`.
