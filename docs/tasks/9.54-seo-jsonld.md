# Задача 9.54: SEO-остаток: JSON-LD и текст `/calculator` (M9)

## Контекст
В штурме (`docs/BRAINSTORM_2026-11.md`, M9 и §8.6) для SEO на неделю 0 остались JSON-LD, текст страницы `/calculator`, `canonical` для адресов с query и внутренние ссылки. `/calculator` закрыт `noindex` до сверки ставок с брокером (шаг a §8.3), и эта задача его не снимает.

## Цель
- JSON-LD: `Organization` и `WebSite` на главной; `BreadcrumbList` на `/prigon`, `/prigon/[slug]`, `/calculator`, `/how-it-works`. Название бренда из `SITE_NAME`, реквизиты и контакты только из `SiteSettings` (`/api/v1/site-settings/`), пустые значения в разметку не попадают. Текст из админки экранируется так, что `</script>` не закрывает тег.
- `/calculator`: заголовок H1 и короткий блок «Як рахуємо» без цифр и обещаний, ссылки на `/prigon` и `/how-it-works`; адрес с query имеет `canonical` на `/calculator`.
- Внутренние ссылки: `/how-it-works` → `/prigon`, `/prigon` → калькулятор (с лендингов на калькулятор ссылка уже есть).
- **`noindex` на `/calculator` остаётся**, в sitemap страница не добавляется.

**Остаток (◐):** снять `noindex` и добавить в sitemap после сверки ставок с брокером; `Vehicle` + `Offer` (вместе с 9.9); `FAQPage`.

## Файлы
Изменить: `frontend/app/page.tsx`, `frontend/app/calculator/layout.tsx`, `frontend/app/calculator/page.tsx`, `frontend/app/how-it-works/page.tsx`, `frontend/app/prigon/page.tsx`, `frontend/app/prigon/[slug]/page.tsx`, `frontend/lib/labels.ts`, `frontend/e2e/seo.spec.ts`, `ROADMAP.md`, `PROGRESS.md`.
Создать: `frontend/lib/jsonld.ts`, `frontend/components/seo/JsonLd.tsx`, `frontend/components/calculator/CalculatorHowWeCount.tsx`.
Не трогать: `.env`, `cars/`, правки задачи 9.50 (кроме одной вставки в `app/prigon/[slug]/page.tsx`, которая коммитится отдельно от правок 9.50).

## Шаги
1. `lib/jsonld.ts`: построители и экранирование (`<`, `>`, `&`, U+2028/2029 → `\uXXXX`).
2. Компонент `JsonLd` (серверный) и подключение на страницах.
3. Блок «Як рахуємо» и ссылки.
4. Проверка CSP (`script-src 'self' 'unsafe-inline'`, тип `application/ld+json` не исполняется) на e2e-стеке.

## Тесты
Playwright `seo.spec.ts`: JSON-LD парсится, типы и поля на каждой странице, значения контактов совпадают с API настроек, пустые реквизиты не выводятся, текст с `</script>` не ломает разметку, `noindex` на `/calculator` остаётся, `canonical` не зависит от query, в sitemap страницы нет. Прогон: `seo`, `landing`, `calculator-config`, `security-headers`.

## Для владельца (LAUNCH_CHECKLIST)
Реквизиты в «Налаштування сайту» попадают в разметку (название юрлица, телефон, email, адрес): заполнять только то, что должно быть публичным. Снять `noindex` с `/calculator` после сверки ставок (прежний пункт чек-листа).
