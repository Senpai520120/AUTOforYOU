# Задача 10.29: советы «як перевірити авто», место под VIN-проверку, аудит ссылок на закрытые флагами разделы

## Контекст
Источник: `docs/audit/41_REVIEW_2026-11-11.md`, находки B7, B9. На карточке C2C-объявления (`frontend/app/local/[id]/LocalListingDetail.tsx`) нет подсказок покупателю, как проверять авто. VIN-проверка заморожена (3.2b, `/vin-check` закрыт флагом `VIN_REPORTS_ENABLED`); есть только партнёрская ссылка carVertical (`PartnerVinLink`, URL из `CARVERTICAL_PARTNER_URL`). Разделы закрыты флагами `C2C_ENABLED` (`/ua`, `/local/*`), `LOTS_ENABLED` (`/listings`), `B2B_ENABLED`, `DEALERS_ENABLED`.

## Цель
- `SiteSettings.listing_check_tips` (текст владельца, по совету в строке, до 10), в белом списке публичного API; на карточке C2C блок «Як перевірити авто перед купівлею» только при непустом поле.
- Место под VIN-проверку на карточке: партнёрская ссылка показывается, только если задан `CARVERTICAL_PARTNER_URL`; закрытый `/vin-check` не открывается.
- Аудит: шапка, бургер, подвал, `sitemap.ts`, `robots.ts`, JSON-LD, Telegram-бот не ведут на закрытые разделы. Найдено и исправлено: `/me/leads` показывал «Переглянути лот» на `/listings/<id>` при `LOTS_ENABLED=false` (теперь по `lots_enabled`). Остальное уже закрыто флагами.
