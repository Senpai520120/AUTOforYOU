## Контекст
Телефон продавца отдаёт только `GET /api/v1/local/listings/<pk>/contact/` (`local_listings/views.py:364-378`): авторизованным, только `active`, throttle scope `contact` (`THROTTLE_CONTACT_RATE`, по умолчанию `20/hour`, `core/settings.py:238`). Модерация идёт в админке (`local_listings/admin.py`), жалобы — `POST /api/v1/reports/` (`reports/views.py:6-8`) и экшены админки (`reports/admin.py:8-61`). Шаги 2 и 5 сценария 3 (`docs/audit/20_SCENARIOS.md`).

Что сейчас в коде:
- **05-S6 (важно):** показ телефона нигде не журналируется (кто, когда, какое объявление). Лимит только почасовой на аккаунт — массовый сбор номеров через несколько аккаунтов или равномерно в течение суток не обнаружить и не остановить (`local_listings/views.py:364-378`, `core/settings.py:238`).
- **05-Q9 (важно):** никто не уведомляется:
  - о новом `pending`-объявлении (создание `local_listings/serializers.py:186-222`, ремодерация `:258-266`) — модератор узнаёт, только открыв админку;
  - о новой жалобе (`reports/views.py:6-8` — голый `CreateAPIView`);
  - владелец объявления не получает уведомления, когда его объявление скрыто по жалобе (`reports/admin.py:8-18` меняет статус через `save()` без причины и без уведомления); автор жалобы не узнаёт результат (`dismiss_report`, `reports/admin.py:46-48` — `queryset.update`).

## Цель

Без токена/с неверным токеном → 400/403, номер не отдаётся. Авторизованные получают телефон как раньше (GET, без капчи). Для гостей — отдельный лимит показов в сутки `THROTTLE_CONTACT_GUEST_DAILY_RATE` (настройка, по умолчанию `10/day` на IP; значение владелец может изменить) → 429 «Ліміт переглядів телефонів на сьогодні вичерпано». Кнопка «Показати телефон» на карточке для гостя разворачивает капчу, а не ведёт на `/login`.

### Тесты (добавлено)
Django:
- Шаг 14: в БД нет открытого IP — после гостевого показа ни одно поле `ContactView` не содержит IP (сравнение значений всех полей со строкой IP), `ip_hash` — 64 hex-символа и равен `hmac.new(PHONE_LOG_IP_SALT, ip, sha256).hexdigest()`; при другой `PHONE_LOG_IP_SALT` (`override_settings`) хэш того же IP иной; пустая соль → гостю 503, номера и записи журнала нет; `PHONE_LOG_IP_SALT` не равен `SECRET_KEY` в `.env.example`.

Playwright (`c2c-phone.spec.ts`):
- Ошибка/обход: гость, два показа при `THROTTLE_CONTACT_GUEST_DAILY_RATE=2/day` в e2e-стеке → третий: «Ліміт переглядів телефонів на сьогодні вичерпано», номера нет; в HTML и в `request.get` страницы объявления номера нет.
