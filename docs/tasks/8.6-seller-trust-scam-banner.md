## Цель
- [ ] **Тип продавца определяет сервер (D1.1/J1.4).** `seller_type` в create/update — только для чтения. При создании: `dealer`, если `request.user.is_verified_dealer`, иначе `private`. В публичных ответах `seller_type=dealer` отдаётся, только пока владелец верифицирован (отзыв роли по 1.2 мгновенно убирает «дилера» со всех его объявлений: функция `users/services.py` отзыва вызывает `sync_listing_seller_type(user)` из `local_listings/services.py`, либо выдача считается по текущему `owner.is_verified_dealer` — исполнитель выбирает один способ и покрывает тестом оба сценария). Data-миграция: объявления с `dealer` у неверифицированных владельцев → `private`. Селектор типа в форме скрыт; для верифицированного показана строка «Ви публікуєте як перевірений дилер».
- [ ] **Бейдж.** «Перевірений дилер» (вместо «Дилер») на карточке и странице; не показывается самозваным. Бейдж «Надійний продавець» по угодам (`seller_has_badge`) не меняется.
- [ ] **Блок продавца.** В детали: `seller_id`, `seller_member_since` (месяц и год регистрации, формат «на сайті з березня 2026»), `seller_active_listings_count`; имя — только через `public_display_name` (1.9), email, телефон, фамилия целиком не отдаются. Ссылка «Усі оголошення продавця» ведёт на `/sellers/<id>`.
- [ ] **Страница продавца.** `GET /api/v1/local/sellers/<id>/` (AllowAny): `display_name`, `member_since`, `is_verified_dealer`, `active_listings_count`, `deal_count`, `avg_rating`, последние отзывы (`rating`, `text`, `created_at`, `author_name` через хелпер), список активных объявлений с пагинацией (тот же сериализатор, что в каталоге; `blocked`, не-`active`, истёкшие — исключены). 404 для несуществующего, неактивного или удалённого пользователя (Q3: «Користувач видалений» не открывается как страница) и для пользователя без единого публичного объявления и отзыва. Throttle на анонимов — стандартный `anon`. Фронт: `frontend/app/sellers/[id]/page.tsx` (SSR, состояния загрузки/пусто/404 по 6.2); пока владелец не решит иначе, страница с `noindex`.
- [ ] **История цены (D5.1, только запись).** Модель `ListingPriceHistory` (`listing` FK, `price`, `currency`, `changed_at`): первая запись при создании, новая — при изменении `price` или `currency` (сравнение `Decimal`, не строк). В публичный API не отдаётся; в админке — read-only inline у объявления. Запись через функцию `record_price_change` в `local_listings/services.py`, вызываемую из create/update сериализаторов.
- [ ] **Баннер предоплаты (C8.1).** Текст хранится в `SiteSettings.prepayment_warning_text` (черновик по умолчанию на украинском: «Не переказуйте передоплату чи «завдаток» продавцю, не побачивши авто та документи. Шахраї часто просять гроші наперед.»); пустой текст = баннер скрыт; поле попадает в белый список публичного `site-settings`. Компонент `ScamWarningBanner` показывается: на странице объявления рядом с блоком контакта, в форме первого сообщения (`WriteSellerButton`), в диалоге над полем ввода (`me/messages/page.tsx`). Ссылка «Правила безпечної угоди» ведёт на `/rules`. Баннер не закрывается и не требует отметки.

## Тесты
Django (`local_listings/tests.py`, `site_settings/tests.py`, `users/tests.py`):
- Неверифицированный POST с `seller_type=dealer` → объявление создано как `private` (поле игнорируется, не 500); верифицированный дилер → `dealer`; PATCH `seller_type` игнорируется.
- Отзыв верификации (действие 1.2) → публичный ответ его объявлений больше не содержит `dealer`.
- Блок продавца: `seller_member_since`, `seller_active_listings_count` верны (не считаются `pending`, `blocked`, `expired`); в ответах списка, детали и страницы продавца нет `email`, `contact_phone`, фамилии целиком (проверка по JSON); имя без части email у пользователя без имени.
- `GET /local/sellers/<id>/`: неактивный/удалённый пользователь, несуществующий id, пользователь без публичных данных → 404; список только `active`; отзывы с `author_name` через хелпер; число запросов к БД не растёт с числом объявлений (`assertNumQueries`).
- История цены: создание → 1 запись; PATCH с той же ценой в другом формате (`"15000"` / `"15000.00"`) → записей по-прежнему 1; смена цены и смена валюты → +1; в публичных эндпоинтах истории нет.
- `site-settings`: поле `prepayment_warning_text` в публичном ответе, пустое значение → пустая строка.

Playwright (`frontend/e2e/c2c-seller-trust.spec.ts`; storageState продавца, покупателя, верифицированного дилера из 0.4):
- Успех: на странице объявления виден баннер предоплаты, блок «на сайті з …», «Усі оголошення продавця» ведёт на `/sellers/<id>` со списком его объявлений и рейтингом; у объявления верифицированного дилера бейдж «Перевірений дилер»; баннер виден в окне первого сообщения и в диалоге.
- Ошибка/обход: обычный продавец отправляет через `request.post` `seller_type: 'dealer'` → в карточке нет бейджа дилера; в форме подачи нет выбора типа продавца; `/sellers/999999` → состояние «Продавця не знайдено», без падения; в HTML страницы продавца и объявления (`page.request.get`) нет email и телефона; пустой `prepayment_warning_text` в админке → баннера нет.
