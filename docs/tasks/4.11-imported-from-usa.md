# Задача 4.11: Поле «Пригнано зі США», VIN для бейджа, ссылка на историю аукциона [ВОЛНА-2]

## Контекст
Новая задача сверки с бизнес-планом (`docs/audit/40_BUSINESS_PLAN_SYNC.md` §4, строка про нишу «американцы»; `docs/ANSWERS.md`, «Сверка с бизнес-планом»: поле, VIN для бейджа и ссылка на аукцион — ВОЛНА-2). Раньше это сидело в 9.1 (Рост); 9.1 соответственно урезается.

Что есть в коде (проверить Grep):
- Модель объявления C2C — `local_listings/models.py` (`LocalListing`), сериализаторы `local_listings/serializers.py`, форма подачи — задача 4.2, поля и фильтры списка — задача 8.3.
- VIN в канонической `vehicles.Vehicle` и декодер NHTSA; на C2C-объявлении отдельного VIN-поля с валидацией нет.
- Платный бейдж «Перевірений американець» (199–299 грн) — 9.41 (Рост), зависит от этой задачи. Здесь бейдж **самозаявленный**, без проверки и без оплаты.

## Цель
- [ ] **Поле `imported_from_usa`** (Boolean, по умолчанию `false`) в форме подачи и редактирования (чекбокс «Пригнано зі США»), в API создания/изменения/деталей, в админке.
- [ ] **VIN обязателен для бейджа.** Поле `vin` (CharField 17, nullable, нормализуется в верхний регистр, без пробелов). Валидация формата: 17 символов `[A-HJ-NPR-Z0-9]` (без I, O, Q); контрольную цифру проверять не обязательно (для европейских авто она не гарантирована) — решение зафиксировано в коде комментарием. При `imported_from_usa=true` без валидного VIN → 400 «Для позначки «Пригнано зі США» вкажіть VIN». Без VIN объявление можно подать, но без бейджа (`imported_from_usa` принудительно `false`).
- [ ] **VIN не светится целиком публично без решения владельца:** в публичной карточке показывается VIN полностью только если владелец включил `LISTING_SHOW_VIN=true` (по умолчанию `false`: показываются последние 6 символов; это защита от клонирования объявлений). Бейдж показывается и при скрытом VIN. Решение по умолчанию — вопрос владельцу в LAUNCH_CHECKLIST.
- [ ] **Уникальность VIN среди активных объявлений** (частичный `UniqueConstraint` или проверка в сериализаторе): второе active-объявление с тем же VIN → 400 «Оголошення з таким VIN уже існує»; защита от дублей и «чужих» авто.
- [ ] **Поле `auction_history_url`** (URLField, nullable, до 500 символов): только схема `https`, хост непустой, без `userinfo` (`user:pass@`), без IP-литералов и `localhost`; допустимый список доменов аукционов (Copart, IAAI, Manheim и т. п.) настраивается в админке (`AuctionHostAllowlist` или `SiteSetting`) — **список не выдумывается в коде**, при пустом списке принимается любой публичный https-хост. **Сервер ссылку не запрашивает** (никаких fetch/preview/redirect-проверок — исключаем SSRF). На фронте ссылка выводится как `<a href rel="nofollow noopener noreferrer" target="_blank">` с текстом «Історія торгів на аукціоні», только если схема `https` (повторная проверка на клиенте от `javascript:`).
- [ ] **Бейдж в карточке и списке:** «Пригнано зі США» (с VIN-признаком «VIN вказано»), в списке/поиске фильтр «Пригнано зі США» (`?imported_from_usa=true`, добавляется в схему фильтров 8.3, индекс), в `docs/openapi.yaml`. Подпись бейджа нейтральная: «зі слів продавця», пока нет проверки (9.41); текст заверения не обещает проверки.
- [ ] Модерация: в админке и очереди модерации (4.3) видно `imported_from_usa`, VIN, ссылку; ссылка отображается как текст, не кликабельная в списке админки.
- [ ] Данные VIN и ссылка проходят существующую фильтрацию антиспама (8.5/`antispam.py`) как текстовые поля.

## Тесты
Django:
- VIN: валидный 17-символьный → принят и нормализован (нижний регистр → верхний); длина 16/18, символы I/O/Q, пробелы внутри → 400.
- `imported_from_usa=true` без VIN → 400; с валидным VIN → 201, бейдж в ответе; без VIN и `false` → 201.
- Дубликат VIN у active-объявления → 400; у архивного/отклонённого — допустим.
- `auction_history_url`: `https://...` принят; `http://`, `javascript:`, `data:`, `ftp:`, `//host`, `https://user:pass@host`, `https://127.0.0.1`, `https://localhost`, `https://10.0.0.1` → 400. При заданном allowlist хост вне списка → 400.
- Тест на отсутствие SSRF: при создании и показе объявления сетевые вызовы замоканы (`requests`/`urllib`/`socket`) и **не вызываются**.
- `LISTING_SHOW_VIN=false` → в публичном API VIN замаскирован (последние 6), в API владельца и админа полный; `true` → полный.
- Фильтр `?imported_from_usa=true` возвращает только такие объявления; чужое объявление нельзя изменить (права как в 4.2).
Playwright (`frontend/e2e/usa-badge.spec.ts`):
- Успех: продавец (storageState) подаёт объявление с чекбоксом, VIN и https-ссылкой → после публикации (или модерации в тестовом стеке) в карточке бейдж «Пригнано зі США» и ссылка «Історія торгів на аукціоні» с `rel` `noopener noreferrer`; в списке фильтр «Пригнано зі США» находит объявление.
- Ошибка/обход: чекбокс без VIN → сообщение об ошибке на форме; `http://` или `javascript:` ссылка → ошибка формы и 400 при прямом POST; в карточке чужого объявления без VIN бейджа нет.
