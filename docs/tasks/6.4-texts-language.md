## Тесты
Django:
- Публичная конфигурация: аноним `GET` → 200; в ответе есть лимиты, равные `override_settings(LOCAL_LISTING_MAX_ACTIVE=7, LOCAL_LISTING_EXPIRY_DAYS=45)`; нет полей с токенами/ключами (проверка по списку ключей ответа); после изменения модели в админке (`save()`) ответ обновился (кэш сброшен).
- `link-token`: при `TELEGRAM_BOT_USERNAME='test_bot'` ответ содержит `bot_username == 'test_bot'`, `link` начинается с `https://t.me/test_bot?start=`; при пустом — `link is None`, 200 (без внешних вызовов, Telegram замокан).
- Язык: регистрация со слабым паролем → 400, текст ошибки не содержит символов `[ыэъё]`; `POST /auth/token/logout/` без refresh → 400, сообщение на украинском. Стандартные ошибки DRF (запрос без токена → 401, неверный метод → 405) тоже украинские (`LANGUAGE_CODE='uk'`; проверка на отсутствие `[ыэъё]` и на непустой не-английский `detail`).
- `payments_enabled`: при `PAYMENTS_ENABLED=False` публичная конфигурация отдаёт `false`, при `True` — `true`.

Playwright (`frontend/e2e/texts.spec.ts`):
- **Успех:** футер показывает телефон и email из фикстуры настроек (заданы в `e2e_seed`); `/rules` содержит число из конфигурации и не содержит `{LOCAL_LISTING_MAX_ACTIVE}`; `/refund` показывает тарифы из фикстуры `PromotionTariff`; `/me/telegram` показывает имя бота из конфигурации.
- **Ошибка/обход:** при пустых контактах в настройках футер не содержит `[` и `заповнити`; при демо-тарифах на главной видна пометка «Тестові тарифи», при проверенных (`page.route` на эндпоинт признака или фикстура) — нет; `/me/telegram` при `link: null` (`page.route`) показывает «ще не налаштований» и не содержит `href="https://t.me/"`.
- `/refund` при `payments_enabled=false` (`page.route` на конфигурацию) показывает «Платні послуги наразі недоступні» и не содержит таблицы тарифов; при `true` — таблицу из фикстуры.
- Язык: на `/`, `/listings`, `/ua`, `/calculator` (после расчёта), `/me/*` текст `body.innerText()` не содержит символов `[ыэъё]` (23-P50 — часть «нет `[... заповнити]` и `{LOCAL_LISTING_MAX_ACTIVE}`»).
