# Задача 1.2b: Проверки is_staff заменены правами по ролям

## Контекст

После 1.2 роли `broker` и `moderator` получают `is_staff=True` (нужен доступ в Django Admin). Поэтому проверки `is_staff` в приложениях пропускают их туда, куда им нельзя (ревью безопасности 1.2, пункт 2). Решение владельца: права задаются ролью, `is_staff` означает только доступ в админку.

Места (поиск code-scout):
- `listings/permissions.py:18` — B2B-доска (`is_verified_dealer or is_staff`);
- `listings/views.py:62` — выдача wholesale в списке; `:78` — деталь wholesale;
- `shipments/views.py:18` — `_visible_to`: `is_staff` видит все контейнеры;
- `integrations/views.py:208` — `LotImportView`, `IsAdminUser` (расход `APIFY_TOKEN`);
- фронт: `frontend/app/b2b/page.tsx:17`, `frontend/components/layout/Header.tsx:48` — `user.is_staff`.

Остальные проверки по перечню code-scout безопасны и не меняются: `users/*` (управление ролями, `is_superuser`), `messaging/*` (`is_broker`/`is_admin_role`), `deals/views.py:97` (`is_admin_role`), `local_listings/admin.py:156` (`is_superuser`), `integrations/management/commands/import_lot.py:108` (CLI, суперпользователь).

## Цель

- [ ] Импорт лотов (`LotImportView`) — только `admin` (`IsAdminRole`: superuser или `role=admin` + `is_staff`). Broker и moderator → 403.
- [ ] B2B-доска и wholesale в списке и деталях — только верифицированный дилер или admin (`is_verified_dealer or is_admin_role`). Broker и moderator без верификации → 403 на доске и розница в списке и деталях.
- [ ] Контейнеры: admin видит все; остальные — только где они в `watchers`. Broker «по своим заявкам» появится в 2.1: пока broker видит только свои (как обычный пользователь).
- [ ] Профиль отдаёт read-only `is_admin_role`; фронт (`b2b/page.tsx`, `Header.tsx`) проверяет `is_verified_dealer || is_admin_role`, не `is_staff`.
- [ ] В отчёте — полный перечень оставшихся проверок `is_staff` и вывод по каждой.

## Тесты

Django: для broker и moderator (с `is_staff=True`) — 403 на B2B-доске (`/api/v1/b2b/…`), в списке и деталях wholesale не видят (розница только), 403 на `POST lots/import/`, `shipments` список пуст и деталь чужого контейнера 404. Admin (role=admin+staff) — 200/видит все. Верифицированный дилер — доска 200. Анонимы — 401 там, где закрыто.
Playwright: успех — дилер видит B2B (есть в `roles.spec.ts`); обход — broker в шапке не видит ссылку «B2B» и на `/b2b` видит «Доступ обмежено».
