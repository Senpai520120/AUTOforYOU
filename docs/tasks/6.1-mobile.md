# Задача 6.1: Мобильная версия: навигация, сообщения, формы

## Контекст
Мобильной вёрстки как отдельной работы не было. Playwright гоняет только проект `Desktop Chrome` (`frontend/playwright.config.ts:34-38`), поэтому на телефоне не проверялось ничего.

- **08-Q4 (важно):** `frontend/components/layout/Header.tsx:41` — `<nav className="hidden md:flex …">` без бургер-меню. На экране < 768 px нет ссылок «Пригін/аукціон», «Каталог Україна», «Калькулятор», «B2B» / «B2B-доступ». Правая часть (`Header.tsx:57-91`: колокольчик, чат, имя из `user.email.split('@')[0]`, «Вийти») стоит в одной строке с логотипом и подписью «Перекупам UA» (`:38`); на 360 px может не поместиться (в аудите не проверено в браузере).
- **08-Q5 (важно):** `frontend/app/me/messages/page.tsx:144-145` — список диалогов `<aside className="w-72 … flex-shrink-0">` всегда стоит рядом с тредом внутри `flex` (`:143`, `minHeight: 480`). На телефоне тред сжимается до ~80 px.
- Связанные желательные находки того же места (включены в задачу):
  - **09-Q15:** форма калькулятора всегда `grid grid-cols-2` (`frontend/app/calculator/page.tsx:56`); таблица разбивки из 3 колонок без `overflow-x-auto` (`frontend/components/calculator/CalcBreakdown.tsx:20`).
  - **10-Q9:** форма объявления `grid-cols-2`/`grid-cols-3` без брейкпоинтов (`frontend/components/local/LocalListingForm.tsx:235,303,330`); шапка `/ua` — `flex justify-between` без переноса (`frontend/app/ua/page.tsx:47-63`); кнопки «удалить/главное» у фото видны только по hover (`LocalListingForm.tsx:51` — `opacity-0 group-hover:opacity-100`; `frontend/components/local/PhotoUploadBlock.tsx:117`) — на тач-устройствах недоступны.
- Недостающие тесты из `docs/audit/23_TESTS.md`: **23-P43** (мобильная версия), **23-P44** (мобильные формы).

## Цель
- [ ] На ширине < 768 px в шапке есть кнопка-бургер (`aria-label="Меню"`, `aria-expanded`, `aria-controls`), открывающая панель со всеми ссылками десктопной навигации (включая B2B / B2B-доступ по тем же условиям, что `Header.tsx:48`), ссылками «Кабінет», «Вийти» / «Увійти», «Реєстрація».
- [ ] Меню закрывается: по повторному нажатию, по Esc, по клику по ссылке, при смене маршрута (`usePathname`).
- [ ] На 360 px шапка в одну строку без горизонтального скролла: подпись у логотипа и имя пользователя прячутся на `< sm`, иконки уведомлений/сообщений остаются.
- [ ] `/me/messages` на `< md`: показывается либо список диалогов (без `?conv=`), либо тред (с `?conv=`) на всю ширину; в треде есть кнопка «← Діалоги», возвращающая к списку. На `≥ md` поведение как сейчас (две колонки).
- [ ] Калькулятор: форма `grid-cols-1 sm:grid-cols-2`; разбивка обёрнута в `overflow-x-auto`, на 375 px нет горизонтального скролла страницы.
- [ ] Форма объявления: сетки `grid-cols-1 sm:grid-cols-2` / `sm:grid-cols-3`; кнопки управления фото видимы всегда на тач-устройствах (`opacity-100 sm:opacity-0 sm:group-hover:opacity-100` или `@media (hover: none)`), размер области нажатия ≥ 32 px.
- [ ] Шапка `/ua` переносится (`flex-wrap gap-2`).
- [ ] Ни одна публичная страница и страница кабинета не даёт горизонтального скролла на 375 px (`document.documentElement.scrollWidth <= clientWidth`).
