## Цель
- [ ] Есть общие компоненты `LoadingState` (Spinner с `role="status"` и текстом «Завантаження…»), `EmptyState` (заголовок, подсказка, необязательная кнопка-действие), `ErrorState` (понятный текст + кнопка «Спробувати ще раз», вызывающая повторную загрузку) и `ConfirmDialog` (заменяет `window.confirm`).
- [ ] Есть единая функция `getErrorMessage(err)` в `frontend/lib/errors.ts`: сеть → «Немає з'єднання з сервером», 401/403 → «Немає доступу», 404 → «Не знайдено», 429 → «Забагато запитів, спробуйте пізніше», 5xx → «Сервіс тимчасово недоступний»; для 400 — первое сообщение из `err.data` (`detail`, `non_field_errors`, первое поле). Текст исключения сервера (500) пользователю не показывается.

- [ ] C2C: при ошибке загрузки регионов форма подачи и фильтры показывают `ErrorState` с повтором; `/local/[id]/edit` при 404 показывает «Оголошення не знайдено», при 403 — «Немає доступу», при прочих — `ErrorState` (без молчаливого редиректа на `/ua`); `/local/new` во время загрузки показывает `LoadingState`; `PromoteModal` при пустом списке тарифов — «Просування тимчасово недоступне», при ошибке — `ErrorState`.
